Shellder

Shellder is our SSH terminal for macOS and Linux. All hosts of your ~/.ssh/config get their window in Shellder. On the right, the window holds terminals in tabs and splits. On the left, the side bar shows the load of the machine (CPU, memory, GPU, disks) and opens what the machine holds (files, tmux sessions, containers, ports). In the background, Shellder keeps the connections open and answers the login questions of ssh with the passwords and TOTP secrets that you store in your keychain.

Shellder 是我们为 macOS 和 Linux 写的 SSH 终端。~/.ssh/config 里的主机在 Shellder 里各有一个窗口。窗口右边是终端，可以开多个标签页，也可以分栏。左边的侧栏显示这台机器的负载（CPU、内存、GPU、磁盘），并能打开机器上的内容（文件、tmux 会话、容器、端口）。Shellder 在后台保持连接。ssh 登录时要密码或验证码，Shellder 就用你存在钥匙串里的那一份来回答。

Connection连接

Shellder keeps ssh -M master connections open in the background because what the windows start (terminals, file listings, port forwards) can then reuse the open connection and skip the login. In the main window, the switches connect the hosts. When you also lock a host, Shellder reconnects that host after drops. You choose the waits between attempts and the moment at which Shellder gives up. To log in, Shellder answers the questions of ssh with the secrets that you store in your keychain (passwords, key passphrases, TOTP secrets). These secrets share the "shellder vault" item of the keychain. When ssh meets an unknown host key, Shellder shows you the fingerprint so that you can accept or refuse the key.

When the entry of a host sets ControlPath, the commands that you run in other programs (ssh, scp, rsync, VS Code Remote) also reuse the master connection and skip the login. Shellder reads ~/.ssh/config (Include and ProxyJump included) and leaves the file unchanged.

Shellder 在后台保持 ssh -M 主连接，因为窗口里新开的东西（终端、文件列表、端口转发）都能复用这条已经连好的连接，跳过登录。在主窗口里，开关负责连上主机。再给主机上锁，Shellder 就在断线后自动重连这台主机。两次重试之间等多久、什么时候放弃，都由你来定。登录时 ssh 的提问，Shellder 用你存在钥匙串里的凭据（密码、密钥口令、TOTP 密钥）来回答。这些凭据共用钥匙串里的“shellder vault”条目。遇到未知的主机密钥，Shellder 把指纹显示给你，由你决定接受还是拒绝。

主机条目设了 ControlPath 时，你在别的程序里运行的命令（ssh、scp、rsync、VS Code Remote）也复用这条主连接，跳过登录。Shellder 读取 ~/.ssh/config（包括 Include 和 ProxyJump），文件本身保持原样。

Installation安装

Download Shellder from the releases page or build Shellder from the sources:

从 Releases 下载 Shellder，或者从源码构建：

git clone https://github.com/Phantom1003/Shellder.git
cd Shellder
./build.sh --install   # macOS: build/Shellder.app → ~/Applications
./build.sh             # Linux: build/*.deb, build/*.AppImage

After the installation, shellder also works from the command line:

安装之后，shellder 也可以当命令行工具用：

shellder hosts               # Host entries and their ControlPath
shellder lock myserver       # keep this host connected
shellder status              # UP/down per locked host
