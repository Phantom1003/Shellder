SSH connections,
kept warm. SSH 连接，
随时可用。

A menu bar app for macOS and Linux that holds your ssh master connections open and answers their prompts from your keychain. Every later ssh, scp, rsync or VS Code Remote connects at once: no password, no passphrase, no one-time code.

一个 macOS 和 Linux 上的菜单栏应用：在后台保持 ssh 主连接，并从钥匙串里取出答案替你回答提示。之后的每一次 ssh、scp、rsync 或 VS Code Remote 都立刻连上，不用再输密码、密钥口令或一次性验证码。

Your ssh config, nothing else只认你的 ssh 配置

Every Host of ~/.ssh/config is listed, Include followed, and the file is never written to. There is nothing to set up twice.

列出 ~/.ssh/config 里的每个 Host，跟随 Include，并且从不改写这个文件。没有第二份配置要维护。

A switch and a lock一个开关，一把锁

The switch connects. The lock keeps it connected: a dropped link comes back by a reconnect rule of your choosing, and a failed login never hammers the server.

开关负责连接，锁负责保持：连接断开后按你定的重连规则恢复，登录失败也不会反复冲击服务器。

Prompts answered for you提示自动回答

Passwords, key passphrases and TOTP codes are typed into a terminal of ssh's own. Unknown host keys are shown with their fingerprint for you to accept.

密码、密钥口令和 TOTP 验证码直接输入到 ssh 自己的终端里。未知的主机密钥会连同指纹一起显示，由你决定是否接受。

Secrets stay in the keychain密钥只在钥匙串里

One keychain item, so one permission dialog at most. A secret leaves it only towards an ssh the app started; no command reads one back out.

只用一个钥匙串条目，所以最多只弹一次授权。密钥只会交给应用自己启动的 ssh，没有任何命令能把它读出来。

A Console per host每台主机一个控制台

Load, CPU, memory, GPUs, disks, network and processes beside terminals of its own: shells, tmux and screen sessions, containers, cluster jobs, port forwards.

负载、CPU、内存、GPU、磁盘、网络和进程，旁边就是它自己的终端：shell、tmux 与 screen 会话、容器、集群作业、端口转发。

Files, side by side文件并排浏览

The host's tree next to yours. Drag to copy, with the progress underneath; a copy that stopped halfway goes on from where it was.

主机的目录树和本机的并排显示。拖动即可复制，进度显示在下方；中途停下的复制可以从断点继续。

Start in a minute一分钟上手

git clone https://github.com/Phantom1003/Shellder.git
cd Shellder
./build.sh --install   # macOS: build/Shellder.app → ~/Applications
./build.sh             # Linux: build/*.deb, build/*.AppImage

Or take a built one from the releases. Then flip the switch next to a host: the first time, Shellder asks for the password and offers to keep it in the keychain. Lock the host and it reconnects on its own from then on.

也可以直接从 Releases 下载构建好的版本。然后打开某台主机旁边的开关：第一次连接时 Shellder 会询问密码，并提供保存到钥匙串的选项。给主机上锁之后，它就会自己重连。

shellder hosts               # Host entries and their ControlPath
shellder lock myserver       # keep this host connected
shellder status              # UP/down per locked host
