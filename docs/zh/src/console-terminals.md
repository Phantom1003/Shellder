# 终端

终端标签页是接在 `ssh -t host …` 的屏幕 pty 上的 xterm.js；标签页开在本机时，接的是你的登录 shell。表情符号和东亚字符的宽度按 Unicode 11 计算。文字默认由网页视图自己绘制；在[控制台设置](console-settings.md)里打开“使用 WebGL 绘制”后，只要视图能提供 WebGL 上下文，终端就改用 WebGL 绘制。本页讲终端在显示 shell 之外还做些什么：剪贴板、链接、查找条、两种铃、系统通知、密码代填和 Shell 集成。标签页、分组和分栏见[标签页与分组](console-tabs.md)。

## 剪贴板、快捷键与字号

主机上的程序写入剪贴板的内容（OSC 52：开了 `set-clipboard on` 的 tmux、启用了剪贴板的 vim）会进入本机的剪贴板。程序请求读取剪贴板时什么也得不到，因为主机上打印出来的任何内容都可以发出这种请求。

| 快捷键 | 作用 |
| --- | --- |
| ⌘C | 复制选中的内容；没有选中时按键交给 shell，也就是中断 |
| ⌘V | 粘贴 |
| ⌘A | 全选 |
| ⌘K | 清空终端 |
| ⌘+、⌘−、⌘ 加滚轮 | 放大或缩小文字 |
| ⌘0 | 文字恢复为 13 点 |

字号对窗口里的每个终端和之后打开的终端都生效，并且会保存下来，下一个窗口沿用。在控制台设置里打开“选中即复制”后，选中的内容会随选随复制。

在终端里按住一个键会连续输入：应用为自己关掉了 macOS 的重音字符弹窗（按住不放），终端类应用都这样做。

全部快捷键，包括发给 shell 的那些（⌘←、⌥→、⇧↩ 等），见[快捷键](keys.md)。

## 链接

### 网页链接

文字里的网址，以及程序标记出来的链接（OSC 8），都是链接。⌘ 点击（Linux 上是 Ctrl 点击）在浏览器里打开；普通点击就只是点击，不会打开任何东西。

### tmux 里的链接

tmux 只把程序的链接转给它确知支持链接的终端。

- 控制台启动的 tmux（[会话面板](console-sessions.md)里的会话，或新建的会话）会用 `tmux -T hyperlinks` 告诉它这一点。这个选项从 tmux 3.2 起可用，链接本身要到 tmux 3.4 才有。
- 你自己在 shell 标签页里启动的 tmux，需要在 `tmux.conf` 里加上这一行：

  ```
  set -as terminal-features ",xterm-256color:hyperlinks"
  ```

  否则像 Claude Code 的会话名这样的链接只会显示成普通文字。

### 路径链接

路径也是链接：绝对路径总是；shell 报告了自己所在的目录时（见下文“Shell 集成”一节），该目录下的相对路径也是。

- ⌘ 点击在[文件面板](console-files.md)里显示这个文件：进入它所在的目录并选中它。以斜杠结尾的路径则进入那个目录。
- ⌥⌘ 点击改为在当前分组的预览标签页里显示这个文件。
- 如果终端所在的主机不是窗口当前显示的主机，窗口会先切换到那台主机，和主机菜单的做法一样。已经有另一个窗口在显示那台主机时，那个窗口会被调到前面，文件则显示在本窗口对应的文件窗口里。

## 查找条

⌘F 在终端右上角打开查找条。

- 每一处匹配都会标出，当前这一处更亮，查找条上显示计数。
- ↩ 跳到下一处，⇧↩ 跳到上一处；查找条上的箭头作用相同。
- 输入里有大写字母时，查找区分大小写。
- Esc 收起查找条，键盘焦点回到终端。

预览标签页里用的是同一个查找条。

## 终端菜单

在终端上按右键打开终端菜单：

| 菜单项 | 作用 |
| --- | --- |
| 复制（界面上写作“拷贝”） | 复制选中的内容 |
| “粘贴” | 粘贴 |
| “全选” | 选中终端里的全部内容 |
| “选中上一条输出” | 选中上一条命令的输出（需要 Shell 集成） |
| “查找…” | 打开查找条 |
| “清空” | 清空终端 |
| “在‘文件’中打开” | 在文件面板里显示 shell 当前所在的目录；Shell 集成关闭时是它启动时的目录。侧栏折叠着的话会为此展开 |

快捷终端没有侧栏，最后一项换成切换背景的那一项（见[快捷终端](console-window.md)）。

## 终端响铃

终端响铃是程序发出的响铃（BEL）。终端在屏幕上时，它按控制台设置里“响铃”一项的选择来表现：

| “响铃” | 表现 |
| --- | --- |
| “闪一下”（默认） | 终端边缘闪一下橙色 |
| “声音” | 播放一个声音 |
| “闪一下并发声” | 两者都有 |
| “都不” | 什么也不做 |

不在视线内的标签页无论哪种选择都会得到标签标记。

声音在“响铃”下面一行选择：系统提示音（在系统的声音设置里选的那个）、系统的其他声音（macOS 上是各个 Sounds 文件夹里的，包括 `~/Library/Sounds`；Linux 上是声音主题里的），或你自己的文件（AIFF、WAV、MP3、M4A、Ogg、FLAC）。旁边的 ▶ 可以试听。

## 就绪提醒

就绪提醒是终端右上角的铃铛按钮，和查找条在同一个角上。它和终端响铃没有关系。点击打开之后，每当终端再次可以输入（命令结束了，这由 Shell 集成报告；或者命令停在一个提问上等待回答），它就提醒你一次，直到你把它关掉或终端结束。

提醒的方式取决于你当时在看哪里：

| 终端所处的位置 | 你得到的提醒 |
| --- | --- |
| 窗口在别的窗口后面 | 一条系统通知，不管“通知”开关是开是关 |
| 窗口在前面，但标签页没有显示，或键盘焦点在另一个分组 | 分组高亮：标签页所在的分组周围出现橙色光晕，直到这个终端得到键盘焦点 |
| 你正看着这个终端 | 一条浮动提示 |

分组的就绪提醒在分组按钮里，紧挨着背景按钮。它把该分组所有标签页的就绪提醒一起打开（之后在这个分组里打开的标签页也算），再点一次一起关闭。之后仍然可以单独开关某个标签页自己的就绪提醒。

就绪提醒的开关随布局一起保存。快捷终端没有就绪提醒。

## 标签标记

没有显示的标签页里发生了什么，会在标签页上留下一个圆点，也就是标签标记：

| 标签标记 | 含义 |
| --- | --- |
| 普通圆点 | 有新输出 |
| 橙色 | 终端响铃或就绪提醒响过 |
| 绿色 | 一条命令正常结束（Shell 集成） |
| 红色 | 一条命令以失败结束（Shell 集成） |

把标签页调出来之后，标签标记就消失。

## 系统通知与浮动提示

没人在看的标签页（标签页没有显示，或它的窗口不在前面）里发生的事会以系统通知的形式告诉你，同时 Dock 图标会请求注意。同样的事发生在前台正显示的标签页里，则是一条浮动提示。

| 事件 | 说明 |
| --- | --- |
| 命令失败 | 需要 Shell 集成 |
| 命令运行超过十秒 | 在它结束时通知；需要 Shell 集成 |
| 命令停在提问上等待 | 输出在 `[y/N]`、`Password:` 或以 `?` 结尾的一行上停了几秒 |
| 终端响铃 | 窗口不在前面时以系统通知告知 |
| 程序自己发出的通知 | OSC 9（iTerm2）、OSC 777（Ghostty 和 rxvt）、OSC 99（kitty） |

kitty 的 OSC 99 支持标题和正文（分块发送的也支持），以及 `o=unfocused` 和 `o=invisible`；程序询问终端支持哪些功能时会得到回答。

OSC 1337 `RequestAttention=yes`（iTerm2）让 Dock 图标持续请求注意，直到应用被激活；`once` 只请求一次。两者都会像终端响铃那样给标签页加上标签标记。

系统通知的规则：

- 它们由控制台设置里的“通知”开关控制。就绪提醒的系统通知不受这个开关影响，关着也会发。
- Shellder 在前台时，系统通知同样以横幅显示（这时它对应的标签页不在视线内）。
- 点击系统通知会调出它的窗口和其中的那个标签页。
- 标签页被看过之后，它发出的系统通知就从通知中心里撤掉。
- 控制台的系统通知最多保留十二条。
- 成百上千地发送通知的程序，每个标签页十秒内只放行几条，其余丢弃。
- macOS 不为应用包之外的可执行文件显示通知（比如 `cargo tauri dev` 运行的版本）：日志里会记一次 `notification not shown` 和原因。

### 通知的声音

系统通知可以带声音，在“通知”下面一行选择，选法和终端响铃的声音一样（默认无）。

- 在 macOS 上，系统的声音由通知中心播放：专注模式下它和通知一起保持安静，并且受系统“通知”设置里本应用的声音开关控制。
- 你自己的文件通知中心播放不了，所以由 Shellder 自己播放，不管是否处于专注模式。把文件复制一份到 `~/Library/Sounds`，它就会列在系统的声音里。
- 终端响铃以带声音的系统通知告知时，不会再另外播放响铃的声音。

## 标签进度条

程序报告的进度（OSC 9;4，来自 ConEmu，systemd、winget 等都会发送）显示为标签进度条，也就是标签页底部的一根细条。快捷终端没有标签栏，进度条画在终端的顶边。

- 红色表示出错，橙色表示暂停；有一小段来回滑动表示程序没有给出百分比。
- 它在下一个提示符出现时、终端结束时，或程序最后一次报告进度十五秒之后消失。

## tmux 里的程序

tmux 窗格里的程序只能通过 tmux 被听到。

- 终端响铃能自己传出来，除非 `tmux.conf` 里设了 `bell-action none` 或 `visual-bell on`。
- 所有通知都会被 tmux 留下，除非程序用 tmux 的 passthrough 把它包起来（程序发现自己在 tmux 里时会这样做），并且 `allow-passthrough` 是打开的。
- 控制台启动的 tmux 发现 `allow-passthrough` 关着时，会为它的服务器打开这个选项；你设成 `all` 的则保持不变。
- 你自己在 shell 标签页里启动的 tmux，需要在 `tmux.conf` 里写上 `set -g allow-passthrough on`。

## 粘贴确认

把多行内容粘贴进一个不读取括号粘贴（bracketed paste）的 shell，除最后一行外，每一行一落地就会被执行。所以粘贴确认（终端上方的一个小条）会先问一句：⌘↩ 或“粘贴”执行粘贴，Esc 取消。

现在的 shell 和编辑器都读取括号粘贴，这时不会询问。这个提问对应控制台设置里的“粘贴多行前先询问”开关。

## 密码代填

标签页里的 shell 自己要密码（`sudo`、`su`），而这台主机保存了密码时，终端右上角会出现密码代填。它会写明是哪个账户的密码（`alice@work`）。

**何时出现。** 光标所在的行以密码提示结尾，光标停在它后面，并且输出已经静止了片刻。密码提示等待期间才保存的密码（在主窗口的凭据卡片里保存，或用 `shellder add-secret`）也会在那时出现代填。

**它做什么。** 点击“输入”或按 ⌘↩，就把保存的密码连同一个回车输入进去。这一步在应用一侧完成，页面始终看不到密码。不点击、不按这个键，就什么也不会输入。

**如何消失。** 输入别的任何内容、点 ×，或一分钟没有回应，密码代填就收起，同一个提示不会出现第二次代填。密码被删除时，正显示着的密码代填会收回；再次保存密码后，同一个提示会重新出现代填。

**用的是哪台主机的密码。** 是打开这个标签页时的那台主机。

- shell 里又输入 `ssh` 去了另一台主机，代填的仍然是标签页所属主机的密码。
- 本机上的标签页没有保存的密码，所以没有代填。
- 提示里带有 `user@host`（从 shell 登录另一台主机）或要的是密钥口令（passphrase）时，不会代填：保存的密码是这台主机的。

凭据在[主窗口](main-window.md)的主机页上保存；ssh 自己的提问在[提示窗口](prompt-window.md)里回答，不在这里。

## Shell 集成

从控制台启动的 shell（新标签页、“在此打开 shell”）会在启动时得到 Shellder 的几行脚本，支持 bash、zsh 和 fish。tmux 或 screen 会话不在此列：它们的 shell 早就启动了。其他 shell 原样启动。Shell 集成对应控制台设置里的“Shell 集成”开关。

### 它标记什么

- 提示符、命令，以及命令的结束和退出状态（OSC 133）。iTerm2、VS Code 和 Ghostty 用的也是这一套，所以已经装了它们的集成的 shell 同样能被识别。
- shell 所在的目录（OSC 7）。

### 控制台用它做什么

- 用目录给标签页命名，除非 shell 自己设置了标题。
- 新开 shell（⌘T、新建按钮）时，进入键盘焦点所在的 shell 的目录。
- ⌘↑ 和 ⌘↓ 滚动到上一个或下一个提示符标记。跳到的那条命令，从提示符到输出结束，会被框出来片刻。
- ⌘⇧A（终端菜单里的“选中上一条输出”）选中上一条命令的输出。
- 报告命令结束和命令在等待输入（即上文的标签标记、系统通知和就绪提醒）。
- 关闭仍有命令在运行的标签页或窗口之前先询问（“关闭仍有命令运行的标签前先询问”开关）。
- 让相对路径的路径链接和“在‘文件’中打开”能找到目录。

### shell 如何得到它

在主机上，这几行脚本随 ssh 命令一起送过去，落在为这个标签页建的一个目录里，shell 读完就把它删掉。你的 dotfiles 不会被写入任何东西。

| Shell | 方式 |
| --- | --- |
| bash | 作为交互式 shell 的 rcfile，它先读取登录 shell 会读的文件（`/etc/profile`，然后是 `~/.bash_profile`、`~/.bash_login` 或 `~/.profile`）。标记命令开始需要 bash 4.4（`PS0`）；更旧的 bash 只标记提示符和目录 |
| zsh | 通过 Shellder 提供的 `ZDOTDIR`，其中的 `.zshenv` 会把你自己的 `ZDOTDIR` 换回来，所以你的文件照常读取。钩子在第一个提示符出现时挂上，在 `.zshrc` 之后 |
| fish | 通过 `XDG_DATA_DIRS` 上的一个 `vendor_conf.d` |

### 提示符主题与 tmux

会重画提示符的主题（Powerlevel10k）可能把提示符结束的标记丢掉。这时命令名只能尽量从那一行里读出来。Powerlevel10k 自己的 `POWERLEVEL9K_TERM_SHELL_INTEGRATION=true` 可以把标记补回来。

在 tmux 里，内层 shell 的提示符标记到不了控制台。
