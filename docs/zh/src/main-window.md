# 主窗口

主窗口里能看到 ssh 配置中的每一台主机，以及它的连接状况。左边是主机列表，右边是所选主机的主机页，下方可以打开日志面板。主机的连接、锁定、凭据和端口转发都在这里设置；主机上的 shell、文件和读数则在它的[控制台](console.md)里。

## 主机列表

`~/.ssh/config` 里的每个 `Host` 条目（包括用 `Include` 引入的文件里的）在主机列表中各占一个主机行。点击某一行即选中这台主机，右边显示它的主机页。拖动列表的右边缘可以调整宽度。

主机行从左到右依次是：

- **状态点**：表示连接状态（见下表）；指针停在上面会显示状态的名称；
- 主机名，下面是 ssh 解析出的地址（`user@hostname`）。`ssh -G` 还没有返回时这一行显示“解析中…”，解析失败时显示“配置错误：…”；
- **控制台按钮**：只在指针位于这一行时出现。它打开这台主机的[控制台](console.md)，但不会选中这台主机；
- **连接开关**：打开是尝试连接一次，关闭则关掉主连接。拨动开关同时会选中这台主机，主机页随即显示这次尝试的进展。详见[开关与锁](switch-and-lock.md)。

状态点和连接开关用同一种颜色：

| 颜色 | 含义 |
|---|---|
| 灰色 | 关闭 |
| 黄色 | 正在连接或重试，或者在等它的跳板主机 |
| 绿色 | 主连接已建立 |
| 蓝色 | 主连接已建立，并且主机已锁定 |
| 青色 | 已有主连接，但不是 Shellder 自己的（由带 `ControlMaster auto` 的交互式 `ssh` 留下）。锁不会保持这种主连接；“接管”可以替换它 |
| 红色 | 上一次尝试失败。状态点保持红色，直到开关再次打开 |

开关只要处于关闭状态就是普通的灰色，不管上一次尝试的结果如何。

ssh 配置里没有任何 `Host` 条目时，主机页显示“~/.ssh/config 里没有 Host 条目”。

## 列表工具栏

列表工具栏是主机列表下方的一排按钮。

| 按钮 | 快捷键 | 作用 |
|---|---|---|
| 重新加载 | ⌘R | 重新读取 `~/.ssh/config` |
| 编辑 | ⌘E | 在你的编辑器里打开 `~/.ssh/config`。Shellder 从不写这个文件 |
| 设置 | ⌘, | 打开[设置窗口](settings.md) |
| 更新 | | 只在有新版本时出现；打开设置窗口，在那里安装 |
| 日志 | ⌘L | 打开和收起日志面板 |

主机列表可以收起，让主机页占满整个窗口：主机页左上角的按钮负责收起和展开（⌘⇧S）。这个选择保存在本机。

## 主机页

主机页是窗口的右侧：所选主机的全部信息，分成几张卡片。从上到下依次是：连接卡片、提示卡片（主机的配置有需要说明的情况时才有）、工具卡片、凭据卡片和配置卡片。

### 连接卡片

连接卡片说的是连接本身。

- **主机名**，下面是**状态行**：再画一次状态点，并用文字写出状态及其持续的时间。状态有：“未连接”“连接中…”“已连接”“已连接（无套接字）”“已连接（外部主连接）”“已断开，5 秒后重试”“重试中…”“等待跳板主机 …”和“失败（详见日志）”。跳板主机的状态行还会写出经由它连接的主机。
- 状态行下面是主机解析出的地址（`user@hostname`，端口不是 22 时带端口，有 `ProxyJump` 时带“经由 …”），以及同一个 `Host` 条目的其他名字（“别名：…”）。
- **连接按钮**在右边，显示哪几个取决于当前状态：

| 按钮 | 何时显示 | 作用 |
|---|---|---|
| “锁定” / “解锁” | 始终 | 上锁和解锁。锁定时如果主机是关闭的，会先把它打开 |
| “连接” | 主机处于关闭状态 | 与连接开关相同：尝试一次 |
| “断开” | 主连接已建立或正在连接 | 与关闭开关相同：关掉主连接，解除锁定，并关闭经由这台主机跳转的主机 |
| “重新连接” | 主连接已建立或正在连接 | 关掉主连接再重新连接（⌘K）。开关和锁保持不变 |
| “立即重试” | 主机已打开，正在等下一次尝试 | 不再等待，马上重试 |
| “接管” | 现有的主连接不是 Shellder 的 | 关掉那个主连接，启动一个归 Shellder 所有的。主机随之打开 |
| “关闭套接字” | 有主连接 | 运行 `ssh -O exit`，关掉主连接并删除它的套接字；对交互式 `ssh` 启动的主连接同样有效。开关随之关闭，锁也一并解除，经由这台主机跳转的主机也会断开 |

- **保活方式**（“保活”一行）：主连接在主机上运行什么，好让服务器不断开它。可选“无会话 (-N)”“空闲 shell (pty)”和“stdin 上的 cat”，按主机保存。详见[开关与锁](switch-and-lock.md)里的“保活方式”一节。
- **重连规则**（“自定义重连规则”一行）：一个开关。关闭时主机使用设置里的默认规则，开关旁边写着这条规则的摘要（如“5 秒 → 10 分钟，逐次加倍”）。打开后，主机得到默认规则的一份副本作为自定义规则，各个字段显示在下面。详见[开关与锁](switch-and-lock.md)里的“重连规则”一节。
- “最近错误”一行：主机仍处于打开状态（比如正在重试）而此前某次尝试出过错时显示，内容是 ssh 给出的原因。

尝试失败后已经关闭的主机，状态行显示“失败（详见日志）”；具体原因在日志面板里。

### 提示卡片

以下三种情况下，连接卡片下面会多出一张提示卡片：

- **没有 ControlPath。** 卡片标题是“此主机没有 ControlPath”。连接会为它的端口转发保持着，但没有套接字，其他 ssh 命令、控制台和文件窗口都无法复用它。Shellder 从不改动 `~/.ssh/config`，所以卡片给出一段需要你自己加上的配置（`ControlMaster auto`、一个 `ControlPath`、`ControlPersist`），旁边有复制按钮和“编辑配置…”。写在 `Host *` 块里可以对所有主机生效。
- **没有 ControlMaster。** 在 ssh 不支持 ControlMaster 的平台上，卡片会说明：连接为它的端口转发保持着，每个控制台和文件窗口各自登录，提问由 Shellder 回答。
- **配置无法解析。** `ssh -G` 对这台主机执行失败时，一张标题为“ssh -G 主机名 失败”的卡片显示 ssh 的报错。

前两种情况在[没有套接字时](without-a-socket.md)里有说明。

### 工具卡片

工具卡片上有两个大按钮，下面是这台主机的端口转发和直连。

- **控制台**：打开这台主机的[控制台](console.md)（对所选主机按 ⌘T）：主机上的一个 shell，旁边是它的读数、会话、文件和端口。
- **文件**：打开这台主机的[文件窗口](files-window.md)：两个窗格并排，拖动即复制。

两者在有没有主连接时都能用。经由带套接字的主连接时不需要登录；否则窗口自己登录，提问由 Shellder 从钥匙串回答，或者在[提示窗口](prompt-window.md)里转给你。

卡片标题上的 + 可以添加两样东西：

- 端口转发：与控制台[端口面板](console-ports.md)里显示的是同一批。
- “直连…”：按主机自己的地址（ssh 配置里的 `HostName`）直接打开它的一个端口，不经转发；5900 到 5999 的端口用 VNC 查看器打开，其他端口用浏览器打开。

两者都列在按钮下面（端口转发在前），也列在端口面板里。它们保存在本机，所以不开控制台也能一次点击打开端口。

| 行 | 点击 | 行上的按钮 |
|---|---|---|
| 转发行 | `-L` 转发：在本机打开它的近端，未建立时先建立。`-R` 转发：未建立时建立它 | 建立或停止，以及移除。行上写着“已建立”或“未建立” |
| 直连 | 按主机的地址打开这个端口 | 移除 |

### 凭据卡片

凭据卡片列出保险库里为这台主机保存的凭据：密码、密钥口令、TOTP 密钥，每项一行。

- 卡片标题上的 + 添加一种尚未保存的凭据。对话框询问它的值；TOTP 密钥可以填 base32 密钥，或 `otpauth://totp/…` URI。
- 旁边的废纸篓在确认之后删除这台主机的全部凭据。
- 每一行有三个按钮：显示（眼睛）显示保存的值，旁边有复制按钮，密码和口令还会写出字符数；修改（铅笔）询问新的值；删除（废纸篓）把这项凭据从钥匙串里删掉。
- TOTP 一行另有“显示验证码”：当前的验证码和它剩余的秒数，可以拿来和你的身份验证器 App 对照。

显示出来的值不会一直留着：窗口离开屏幕时会重新隐藏。

钥匙串不让打开保险库时，卡片会写明原因。里面存的东西都还在；钥匙串询问时允许 Shellder，然后按“重试”。详见[钥匙串](keychain.md)。

### 配置卡片

配置卡片（界面上的标题是“生效配置”）显示 `ssh -G` 给出的这台主机的最终配置：`HostName`、`User`、`Port`、`ProxyJump`、`ProxyCommand`、`IdentityFile`、`ControlMaster`、`ControlPath`、`ControlPersist` 和 `ServerAliveInterval`，以及这个条目“定义于”哪个文件。

- `ProxyJump` 指向列表里的主机时会标明：那台主机的主连接会先建立，并随这台主机一起保持（见[跳板主机](jump-hosts.md)）。
- `ServerAliveInterval` 为 0 时也会标明：Shellder 为自己的主连接加上 15 秒。
- 卡片标题上的“编辑 ~/.ssh/config…”在你的编辑器里打开这个文件。

## 日志面板

日志面板在两栏下方显示 Shellder 日志的末尾。用 ⌘L 或列表工具栏的日志按钮打开和收起；拖动它的上边缘可以调整高度，高度会被记住。

- 筛选框只留下包含所输入内容的行：主机名、`ERROR` 等等。
- “跟随”让面板始终停在最新一行。
- “打开文件”打开 `shellder.log` 本身。

失败的尝试的原因写在日志里，ssh 输出的每一行（`SSH host: …`）也在，每个提问问了什么、如何回答的（`PROMPT`）同样在。日志始终是英文，并且从不包含凭据。

## 菜单栏图标

在[设置](settings.md)里打开“后台执行”和“显示在菜单栏”之后，Shellder 在菜单栏上有一个图标。

- 点击打开主窗口；主窗口在最前面时再点一次则把它收起。
- 右键点击显示菜单栏菜单。
- 没有任何主连接时图标是淡色的，只要有一个主连接建立就恢复正常。错误和提问不会改变图标。
- 指针停在图标上会显示有几个主连接已建立。

在 Linux 上，面板按原样显示这张深色的图；设置里的“菜单栏图标反色”把它变成浅色，适合深色面板。那里的图标还需要一个 StatusNotifier 宿主（KDE 自带，GNOME 需要 AppIndicator 扩展）。

### 菜单栏菜单

菜单栏菜单目前只有英文，在中文界面下也是如此，所以下面照原样写出各项。

| 菜单项 | 作用 |
|---|---|
| *Open Shellder* | 显示主窗口 |
| 每台主机一个主机子菜单 | 见下文。● 表示主连接已建立，◐ 表示主连接不是 Shellder 的，○ 表示其他情况 |
| *Other hosts (n)* | 主机多得列不下时，其余的主机收在这里：已打开或已连接的主机排在前面，直接列出六台，其余折叠进来 |
| *Connect All*、*Disconnect All* | 打开或关闭全部主机 |
| *Update to …* | 有新版本时出现；打开设置窗口 |
| *Settings* | 打开设置窗口 |
| *Quit Shellder* | 退出应用并关闭它的主连接 |

### 主机子菜单

主机子菜单里的连接按钮与主机页上的相同，随状态显示：*Lock* 或 *Unlock*，然后是 *Connect*、*Disconnect*、*Reconnect*、*Retry now*、*Take over* 和 *Close socket* 中适用的几个。下面还有：

- *Shell*：在处理 `ssh://` 链接的应用里运行 `ssh host`。那个 ssh 不是 Shellder 的：没有可复用的主连接时，它会自己向你提问。
- *Files*：打开这台主机的文件窗口。
- *Console*：打开这台主机的控制台。
- *Show in Shellder*：打开主窗口并选中这台主机。
