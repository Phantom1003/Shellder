# 文件窗口

文件窗口每台主机一个，里面是并排的两个窗格。每个窗格显示一台机器的文件树：这台主机、本机，或另一台主机。从一个窗格拖到另一个窗格就是复制。文件树、复制状态条和复制列表与控制台的文件面板里的是同一套，完整的说明在[文件面板与预览](console-files.md)；本页只讲这个窗口多出来的东西和不同之处。

## 打开窗口

- 主机页的工具卡片上的“文件”按钮（见[主窗口](main-window.md)）；
- 菜单栏菜单里这台主机的子菜单中的“文件”；
- 控制台文件面板的文件工具栏的最后一个按钮，或它右键菜单里的“在文件窗口中打开”，它们还会让窗口里显示这台主机的窗格转到面板的当前文件夹（见[文件面板与预览](console-files.md)）。

第一次打开的窗口，左窗格显示这台主机，右窗格显示本机。主机的窗格从账户的主目录开始；主机上有 `~/Shellder` 文件夹时，从这个文件夹开始。本机的窗格从你的主目录开始。

## 两个窗格

一个窗格从上到下是：同在一行的主机选择器和文件工具栏、列标题、文件树、路径栏。除主机选择器之外，其余都与文件面板里的用法相同：排序、展开箭头、选择、文件夹选择器、新建文件夹和文件、重命名和删除，都在那一页说明。窗格比侧栏宽，所以这里的日期带时间。

每个窗格有自己的当前文件夹、自己展开的文件夹、自己的选择和自己的排序。它们也与文件面板无关：在窗口里做的任何操作都不会带动面板的文件树，在面板里做的也不会带动窗口。

## 主机选择器

主机选择器是窗格左上角的按钮，上面写着窗格显示的机器。它的菜单先列出“本机”（在这里本机也算一台主机），然后是 ssh 配置里的每台主机。选中一个，窗格就转到那台机器的主目录。

有主连接的主机经由主连接访问。其他主机则各自登录，见下文“没有主连接时”。

两个窗格都可以显示任意一台机器：这台主机和本机、两台主机，或同一台机器上的两个文件夹。显示同一台机器的两个窗格之间不做复制。

## 复制

从一个窗格复制到另一个窗格有三种方式：

| 方式 | 复制到哪里 |
|---|---|
| 把文件行从一个窗格拖到另一个窗格上 | 落在文件夹上，就复制到这个文件夹里；落在文件上，就复制到它所在的文件夹里；落在空白处，就复制到窗格的当前文件夹里。 |
| 跨窗格复制按钮，即文件工具栏末尾指向另一个窗格的箭头 | 另一个窗格的当前文件夹。复制的是选中的项。 |
| 文件行右键菜单里的“拷贝到 …” | 与跨窗格复制按钮相同。 |

没有选中任何项，或两个窗格显示同一台机器时，跨窗格复制按钮和“拷贝到 …”不可用。文件夹连同里面的所有内容一起复制。

本机与主机之间的复制用 sftp；两台主机之间的复制用 scp。

从桌面拖到显示主机的窗格上的文件也会被复制，进入指针下的文件夹。从另一个窗口（另一个文件窗口，或某个控制台的文件面板）拖进来的文件行同样如此。

## 与文件面板的不同

- 单击文件只是选中它：窗口里没有预览。双击本机上的文件，会用它对应的应用打开它；它的右键菜单里也有“打开”。
- 右键菜单里是“拷贝到 …”（另一个窗格），而不是“上传到这里…”和“下载…”；也没有“在此打开 shell”“预览”和“在文件窗口中打开”。
- 文件工具栏以主机选择器开头，以跨窗格复制按钮结尾；文件面板在这个位置放的是打开本窗口的按钮。
- 在显示本机的窗格上，“删除”是“移到废纸篓”。

## 复制、重名提问与继续

复制状态条横在两个窗格下方，复制列表从它展开。它们属于主机，与这台主机的控制台的文件面板共用：在任何一处发起的复制，两处都会列出；重名提问（“替换”“跳过”“应用于全部”）两处都会显示，只需回答一次。中断的复制可以从已写入的部分继续（▷）。窗口关闭后，复制照常进行。

这些都在[文件面板与预览](console-files.md)里说明：复制状态条、复制列表、重名提问，以及继续一次复制。

## 在本机上删除

在主机上，“删除”是彻底删掉这一项，询问时会说明此操作无法撤销。在本机上则什么都不会被删掉：按钮和菜单项显示为“移到废纸篓”，询问的是“把‘名称’移到废纸篓？”，这一项进入系统的废纸篓，之后还可以放回原处。

## 没有主连接时

文件窗口不依赖主机的主连接。主机没有建立主连接，或它的主连接没有套接字时（见[没有套接字时](without-a-socket.md)），窗口自己登录：

- **目录列表经由一个会话**：一个 `ssh host sh`，在窗口第一次需要列目录时登录，之后一直开着。列目录、新建和删除都由它执行。不管列多少次目录，每台主机只登录一次；Shellder 退出时会话关闭。
- **复制各自登录**：用的是与经由主连接时相同的 sftp（两台主机之间是 scp），只是每次复制自己登录，所以一次复制就要一次登录。在使用一次性验证码的主机上，每次复制用下一个验证码：刚用过的验证码不会再发一次。
- **中断的复制**从已经传到的部分继续，与经由主连接时相同。

这些登录的提问（密码、验证码、主机密钥）与主连接的提问以同样的方式回答：用保存的凭据，或在[提示窗口](prompt-window.md)里回答。

控制台的文件面板和它的预览标签页读取主机的方式相同：有主连接时经由主连接，否则经由会话。
