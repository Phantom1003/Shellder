# 快捷键

控制台的快捷键就是带标签页和分栏的终端通常用的那些；窗口自己的是 ⌘R 和 ⌘⇧S。每个快捷键都可以在控制台设置窗口的“快捷键”页上修改，这个窗口用设置按钮（顶栏右端的齿轮）或 ⌘, 打开，见[控制台设置](console-settings.md)。快捷键保存在本机，对每个控制台窗口都有效。

下面各表是 macOS 上的默认值。Linux 上的默认值是 Ctrl+Shift 那一套（新开 shell 是 Ctrl+Shift+T，依此类推）；实际生效的以“快捷键”页上显示的为准。

## 标签页

| 快捷键 | 作用 |
| --- | --- |
| ⌘T | 在主机上新开一个 shell，放在键盘焦点所在的分组里 |
| ⌘W | 关闭键盘焦点所在的标签页；没有打开的标签页时关闭窗口 |
| ⌘⇧T、⌘Z | 恢复最近关闭的终端标签页，它的命令重新运行 |
| ⌘1 … ⌘8、⌘9 | 切到分组的第几个标签页；⌘9 是最后一个 |
| ⌘⇧]、⌘⇧[、⌃Tab、⌃⇧Tab | 分组的下一个、上一个标签页 |

## 分组

| 快捷键 | 作用 |
| --- | --- |
| ⌘D、⌘⇧D | 分栏：在右边、下面再开一个分组，显示当前标签页显示的内容 |
| ⌘⌥W | 关闭分组和其中所有的标签页 |
| ⌘]、⌘[ | 键盘焦点移到下一个、上一个分组（从左到右，从上到下） |
| ⌘⌥↑ ↓ ← → | 键盘焦点移到那个方向的分组 |
| ⌘⌃↑ ↓ ← → | 分组的分隔线往那个方向移动，每次十个像素 |
| ⌘⌃= | 每个分栏里的分组大小均分 |
| ⌘⇧↩ | 单独显示：分组单独占满标签区，再按恢复 |

标签页、分组和分栏的说明见[标签页与分组](console-tabs.md)。

## 窗口

| 快捷键 | 作用 |
| --- | --- |
| ⌘N | 为这台主机再开一个控制台窗口 |
| ⌘⇧W | 关闭窗口 |
| 按住 ⌘⇧、⌘⇧↑、⌘⇧↓ | 主机轮盘：本机和各台主机围着中心画在标签区上。只按住修饰键片刻就会画出；带方向键则立刻画出。方向键把选择沿圆周移到箭头所指方向的下一台主机（在顶部 → 是顺时针，在右侧 ↓ 是顺时针；到了那个方向的尽头就停住），指针也可以选。松开 ⌘，窗口切换到选中的主机，和主机菜单的做法一样，并把键盘焦点交给那台主机上的一个 shell，窗口里没有时新开一个。Esc 收起轮盘；其他任何键会关闭轮盘并照常起作用 |
| ⌘↩、⌃⌘F | 窗口全屏，再按退出（标签页里正显示密码代填时，⌘↩ 改为输入密码） |
| ⌘⇧I | 沉浸模式：只留终端，没有顶栏、侧栏、标签栏，在 macOS 上也没有标题栏；再按一次恢复。这时终端一直铺到窗口边缘，不留控制台设置里的内边距，窗口的圆角画得很小（macOS），字符格可以贴着角排。不保存：控制台打开时总是带着各个栏。在最左边的分组里按 ⌘⌥←，或按 ⌘⇧L、⌘⇧S，侧栏会出来做一次侧栏访问，键盘焦点离开时收回（⌘⌥→、Esc、再按 ⌘⇧L、从里面打开了标签页） |
| ⌃⌥←、⌃⌥→ | 窗口放到屏幕的左半边或右半边，高度不变（占上半屏的窗口会变成左上四分之一）。沉浸模式下的窗口没有可以拖动的地方，就靠这些键移动；它们会解除窗口的最小尺寸限制，所以小屏幕上也放得下四分之一屏的窗口 |
| ⌃⌥↑、⌃⌥↓ | 窗口向上或向下一步：从下半屏到整屏高，再到上半屏，宽度不变（所以四分之一屏的窗口先回到它那半边，再到另一个四分之一） |
| ⌃⌥↩ | 窗口铺满整个屏幕；在那里再按一次，回到原来的位置 |
| ⌃⌥⇧←、⌃⌥⇧→ | 窗口移到上一块或下一块屏幕（屏幕按从左到右排，左右并列的按从上到下，到头后循环），保持现在的位置：同样的半屏或四分之一屏，否则保持大小和离屏幕角的距离，并限制在屏幕之内 |
| ⌘R | 立刻重新读取状态面板 |
| ⌘⇧S | 折叠侧栏，再按展开 |
| ⌘⇧L、在最左边的分组里按 ⌘⌥← | 侧栏访问：键盘焦点移进侧栏，再移回来（再按 ⌘⇧L、⌘⌥→、Esc）。折叠着的侧栏会为这次访问展开，键盘焦点离开时重新折叠；某一行打开了标签页之后，键盘焦点会自己离开。在侧栏里，Tab 和 ⇧Tab 在各个面板之间切换，文件树有自己的方向键和 ↩，会话、作业、容器和端口的列表用 ↑ ↓ 移动，↩ 相当于单击，⇧↩ 相当于双击 |
| ⌘, | 控制台设置窗口（设置按钮） |
| ⌘Q | 退出 |

主机轮盘、沉浸模式和移动窗口的快捷键，说明见[主机轮盘、沉浸模式与快捷终端](console-window.md)。

## 终端

| 快捷键 | 作用 |
| --- | --- |
| ⌘C、⌘V、⌘A、⌘K | 复制选中的内容（没有选中时是中断）、粘贴、全选、清空终端 |
| ⌘F | 查找条：在终端里查找，或在预览标签页显示的文件里查找（文本、Markdown 页面、PDF）。↩ 和 ⇧↩ 跳到下一处和上一处匹配，Esc 回到终端或文件 |
| ⌘↑、⌘↓ | 终端滚动到上一个、下一个提示符标记（由 Shell 集成设置） |
| ⌘⇧A | 选中上一条命令的输出（位置由 Shell 集成告知） |
| ⌘+、⌘−、⌘0、⌘ 加滚轮 | 文字放大、缩小、恢复为 13 点 |
| ⌘Home、⌘End、⌘PageUp、⌘PageDown | 终端滚动到顶部、底部、上一页、下一页（笔记本上是 fn 加 ⌘ 和方向键） |
| ⌘←、⌘→、⌘⌫ | 向 shell 发送 ^A、^E、^U：到行首、到行尾、删掉整行 |
| ⌥←、⌥→ | 向 shell 发送 ESC b、ESC f：后退一个词、前进一个词 |
| ⇧↩ | 向程序发送 ESC ↩，和 ⌥↩ 一样：换行但不提交这一行（代理程序的输入提示、zsh 的行编辑器），tmux 会把它转过去 |

这些键在终端里的作用见[终端](console-terminals.md)。

## 修改快捷键

在“快捷键”页上，每个键是一个快捷键标签：

- 点击快捷键标签，再按下要改用的键，就改掉它；Esc 中止修改；
- 快捷键标签上的 × 去掉这个键；
- 行上的 + 给这个动作再加一个键；
- 行尾的箭头恢复这一行的默认值，“全部恢复默认”恢复所有行的。

两个动作共用的键会被标出，列表里靠前的动作得到它。
