# 主机轮盘、沉浸模式与快捷终端

控制台窗口有三项功能针对的是整个窗口，而不是某一个标签页。主机轮盘用键盘，或者用鼠标的左右两键，把窗口切换到另一台主机。沉浸模式让窗口里只剩终端，这时窗口靠专门的快捷键移动。快捷终端是一个 shell，在任何应用里按下它的快捷键，就从屏幕顶部滑下来。本页还包括全屏和再开一个控制台窗口。这里写的快捷键是 macOS 上的默认值，都可以修改，见[快捷键](keys.md)。

## 主机轮盘

主机轮盘是画在标签区上的一圈主机：本机在最上面，然后是主机列表里的各台主机，围着中心排开，各自带着列表里的颜色，就像游戏里的武器轮盘。中心写着选中的主机的名字和状态。轮盘打开时，选中的主机就是窗口当前显示的那台。

### 打开

- 按住 ⌘⇧ 片刻。只按修饰键就会画出轮盘；很快按完的 ⌘⇧T 不会让它闪现。
- ⌘⇧↑ 或 ⌘⇧↓ 立刻画出轮盘，并把选中的主机往那个方向移一格。
- 在窗口里任何地方同时按下鼠标左键和右键，立刻以指针为中心画出轮盘（窗口里放得下的话）。“同时”指两键先后相隔不超过 0.4 秒，并且先按的那个还没松开；先按哪个都可以。右键菜单不会弹出，已经弹出的会收起。

窗口里有对话框开着时，轮盘不会打开。

### 选择主机

- 方向键把选择沿圆周移到下一台主机，方向就是箭头在屏幕上指的方向。在顶部时 → 是顺时针，← 是往回；在右侧时 ↓ 是顺时针。到了那个方向的尽头，选择就停在原处，所以依次按 →、↓、←、↑ 正好绕圆一周。
- 指针移到某台主机上也会选中它。
- 用鼠标打开轮盘后，只要还按着键，就按指针相对中心的方向来选，远近不限，移出圆圈之外也算。回到中心，选中的又是窗口正在显示的主机。

### 松开

松开 ⌘，窗口就切换到选中的主机，和[主机菜单](console.md)的做法一样，并把键盘焦点交给那台主机上的一个 shell：

- 窗口里已有的那台主机上的 shell（最先显示的那个），或者
- 窗口里没有时，在键盘焦点所在的分组里新开一个。

所以来回切换，每台主机最多只会开一个 shell。按 ↩ 或点击某台主机，切换的方式相同。选中的就是窗口正在显示的主机时，什么都不变。

用鼠标打开的轮盘，在指针选过主机之后松开任一键，也是这样切换：按下两键，朝某台主机移动，松开。在按下的原处松开，轮盘就留着，可以点击某台主机，或用上面的按键。

### 收起

- Esc，或点击轮盘之外的地方，收起轮盘，什么都不变。
- 修饰键还按着时按下其他任何键（比如 ⌘⇧T），轮盘关闭，那个键照常起作用。

| 快捷键 | 作用 |
| --- | --- |
| 按住 ⌘⇧ | 片刻之后画出主机轮盘 |
| ⌘⇧↑、⌘⇧↓ | 立刻画出，选中的主机往那个方向移一格 |
| 同时按下鼠标左键和右键 | 立刻以指针为中心画出；朝某台主机移动后松开，切换到它 |
| ← → ↑ ↓ | 选择沿圆周移到那个方向的下一台主机 |
| 松开 ⌘、↩ | 窗口切换到选中的主机 |
| Esc | 收起轮盘 |

## 沉浸模式

⌘⇧I 让窗口进入沉浸模式：只留终端，没有顶栏、侧栏和标签栏，在 macOS 上也没有标题栏。再按一次 ⌘⇧I 恢复。

- 终端一直铺到窗口边缘，不留[控制台设置](console-settings.md)里设的内边距。
- 在 macOS 上窗口的圆角画得很小，字符格可以贴着角排。
- 沉浸模式不保存：不管关闭时是什么样，控制台打开时总是带着各个栏。

### 侧栏访问

侧栏仍然可以通过侧栏访问用到。在最左边的分组里按 ⌘⌥←，或按 ⌘⇧L、⌘⇧S，侧栏就会出来，键盘焦点在里面。键盘焦点离开时它又收回去：⌘⌥→、Esc、再按一次 ⌘⇧L，或从里面打开了一个标签页。

### 用快捷键移动窗口

沉浸模式下的窗口没有可以拖动的地方，所以用快捷键移动。这些快捷键在任何控制台窗口里都能用。

| 快捷键 | 作用 |
| --- | --- |
| ⌃⌥←、⌃⌥→ | 窗口放到屏幕的左半边或右半边，高度不变（占上半屏的窗口会变成左上或右上四分之一） |
| ⌃⌥↑、⌃⌥↓ | 窗口向上或向下一步：从下半屏到整屏高，再到上半屏，宽度不变（所以四分之一屏的窗口先回到它那半边，再到另一个四分之一） |
| ⌃⌥↩ | 窗口铺满整个屏幕；在那里再按一次，回到原来的位置 |
| ⌃⌥⇧←、⌃⌥⇧→ | 窗口移到上一块或下一块屏幕，保持现在的位置：同样的半屏或四分之一屏，否则保持大小和离屏幕角的距离，并限制在屏幕之内 |

屏幕按从左到右的顺序排，左右并列的按从上到下，到头后循环。这些快捷键会解除窗口的最小尺寸限制，所以小屏幕上也放得下四分之一屏的窗口。

## 全屏

⌘↩ 或 ⌃⌘F 让窗口进入全屏，再按一次退出。标签页里正显示着[密码代填](console-terminals.md)时，⌘↩ 改为输入密码。

## 再开一个控制台窗口

⌘N 为这台主机再开一个控制台窗口。

## 快捷终端

快捷终端是一个 shell，在任何应用里按下它专用的快捷键，就从屏幕上边缘滑下来，和 Ghostty 的做法一样。它没有顶栏、侧栏和标签栏。

### 快捷键与主机

两者都在[控制台设置](console-settings.md)的“快捷终端”页上。

- **快捷键。** 点击输入框，再按下要用的键，其中要有一个修饰键。⌫ 取消这个快捷键。被系统或其他应用占用的键拿不到，页上会说明。
- **主机。** 快捷终端的 shell 开在那里选的主机上，或者本机。

### 出现在哪里、有多大

- 它从指针所在屏幕的上边缘滑下来，盖在所有其他窗口之上，全屏窗口也不例外。
- 在你拖动它的边缘之前，它和屏幕一样宽，高度是屏幕的三分之一。拖动之后大小会保存下来（按占屏幕的比例）。
- 它始终沿顶部居中：拖动一边时，两边同时移动。

### 背景

快捷终端的背景是最近一次用控制台某个分组的背景按钮选的那种（还没选过时跟随系统外观）。控制台的终端右上角是就绪提醒；快捷终端没有就绪提醒，那个位置是一个背景按钮。用这个按钮或终端菜单可以在深色和浅色背景之间切换。

### 收起

下面任何一种情况都会让它收起：

- 再按一次它的快捷键；
- 在它的提示符处按 Esc（没有命令在运行这一点由 [Shell 集成](console-terminals.md)告知；在程序里，Esc 归程序）；
- 键盘焦点去了别的窗口。

shell 会继续存在，只是隐藏起来，等下一次再用。关掉它的最后一个标签页，或执行 `exit`，会换上一个新的 shell。

在别的应用上方调出的快捷终端，收起时会把键盘焦点还给那个应用，所以 Shellder 的任何窗口都不会跑到前面来。
