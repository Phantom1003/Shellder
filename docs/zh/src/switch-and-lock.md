# 开关与锁

每台主机都有一个连接开关和一把锁。开关的意思是“连接”：尝试一次，连上了能维持多久就维持多久。锁的意思是“保持连接”：连接一断，Shellder 就把它恢复。连接开关在[主窗口](main-window.md)的主机行上，锁定按钮在主机页的连接卡片上。

## 开关

打开一台主机的开关，就是尝试连接一次。

- **尝试成功**：主连接保持着，开关变成绿色。连接能维持多久就维持多久：链路一断，开关就回到关闭。
- **尝试失败**（密码错误、取消了提问、拒绝了主机密钥、主机不可达、配置无法解析）：开关回到关闭，不会重试。状态点变成红色，主机页的状态行显示“失败（详见日志）”，原因在日志面板里。
- **关闭开关**：关掉主连接。“断开”的作用相同。“关闭套接字”还会运行 `ssh -O exit`，对交互式 `ssh` 启动的主连接同样有效。

开关的状态不会被记住：重新启动之后，每台主机都从关闭开始。

### 颜色

主机的状态点和连接开关用同一种颜色：

| 颜色 | 含义 |
|---|---|
| 黄色 | 正在连接或重试 |
| 绿色 | 主连接已建立 |
| 蓝色 | 主连接已建立，并且主机已锁定 |
| 青色 | 现有的主连接不是 Shellder 自己的：由带 `ControlMaster auto` 的交互式 `ssh` 留下。锁不会保持这种主连接，“接管”可以替换它 |
| 红色 | 尝试失败。状态点保持红色，直到开关再次打开 |
| 灰色 | 关闭。开关只要处于关闭状态就是普通的灰色 |

## 锁

锁让连接保持着。锁定一台主机时，如果它是关闭的，会先把它打开；此后 Shellder 自己负责恢复连接：

- 链路断开后，按重连规则重新连接；
- Shellder 启动时，锁定的主机会重新打开。

只有刚连上就断、反复如此的链路，才会在三次尝试之后放弃。

锁跟着开关走。不管是什么让开关关闭的，是你还是一次失败的尝试，锁都随之解除。手动解锁不会动现有的连接，只是以后不再恢复它。

锁定的主机是唯一跨启动保存的东西，也是 `shellder lock`、`unlock` 和 `status` 这几个命令操作的对象。

## 重连规则

重连规则决定 Shellder 在每次重试之前等多久，以及一共坚持多久。

- **默认规则**在[设置窗口](settings.md)里，所有主机都按它来：等待时间从 5 秒起逐次加倍，最长 10 分钟，永不放弃。
- **自定义规则**可以在主机页上单独给某台主机：连接卡片里保活方式下面的“自定义重连规则”一行。它按主机保存，是一条完整的规则，所以之后修改默认规则不会影响到它。

一条规则有这些字段：

| 字段 | 含义 |
|---|---|
| “重试间隔” | “逐次加倍”：每次等待是上一次的两倍，直到最长等待为止。“固定”：每次重试等待的时间相同 |
| “首次等待”（固定时叫“等待”） | 第一次尝试失败之后等多久，单位是秒（1 秒到 1 小时） |
| “最长等待” | 加倍到多少为止，单位是秒（最长一天）。固定间隔时不显示 |
| “放弃” | 连接断开多久之后关闭开关（锁随之解除），或者“从不” |

等待时间这样计算：

- 立刻失败的尝试（服务器不可达、登录被拒绝）会让等待时间往上数。连接维持过一段时间之后，则从头数起。
- 逐次加倍时，连续第三次快速失败会直接跳到最长等待，所以错误的密码不会反复冲击服务器。
- 固定间隔时每次都是你设的那个时间；对那些登录失败几次就封禁客户端的主机，请把它设得合理一些。
- 修改规则会立刻影响到正在等待下一次尝试的主机：等待时间按新规则重新计算。

## 保活方式

有些服务器会在几秒钟之内关掉没有会话的 `ssh -N` 连接。这时主连接和其他断线一样结束：未锁定的主机带着错误关闭，锁定的主机重试，快速失败几次之后放弃。遇到这种情况，请在主机页连接卡片的“保活”一行里换一种保活方式。这个选择按主机保存。

| 方式 | 服务器看到的 | 说明 |
|---|---|---|
| “无会话 (-N)”，默认 | 一个没有会话的连接 | 最干净，但有些服务器不接受 |
| “空闲 shell (pty)” | `sshd: you@pts/N → -bash`，`w` 里一个空闲的登录 | 和开着的终端没有区别；断开时收到 SIGHUP |
| “stdin 上的 cat” | `sshd: you@notty → cat` | 没有 pty，不执行登录脚本；链路断开时因 EOF 退出 |
