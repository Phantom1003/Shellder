# 端口面板

端口面板用来让本机够得着主机上的端口。它有三个分区：你建立的端口转发、直连，以及主机自己的端口。点击一行，就在本机用 VNC 查看器或浏览器打开这个端口。

## 端口转发

端口转发有两个方向：

| 方向 | 作用 |
|---|---|
| `-L` | 本机端口通向主机端口。 |
| `-R` | 主机端口通向本机端口。 |

端口转发分区（界面上目前的标题是“隧道”）标题上的 + 添加一条。两端的端口可以自己指定，也可以交给 Shellder：本机这边由它选一个空闲端口，主机那边由 sshd 分配。`-L` 转发必须给出主机端口，`-R` 转发必须给出本机端口。

端口转发建在主连接上（`ssh -O forward`），所以主机必须是带套接字连接的（见[没有套接字时](without-a-socket.md)）。主连接在，它就在。

### 转发行

每条端口转发有一个转发行，上面写着它是否已建立。

| 控制项 | 作用 |
|---|---|
| 单击 `-L` 转发 | 在本机打开它的近端；未建立时先建立。 |
| 单击 `-R` 转发 | 未建立时建立它。本机这边没有可打开的东西。 |
| 建立按钮 | 建立这条转发；重新连接之后就用它把转发再建起来。 |
| 停止按钮 | 停止这条转发（`ssh -O cancel`）。这一行还在。 |
| × | 移除这条转发（界面上目前的提示写作“删除这条隧道”）。 |

`-L` 转发的远端是 VNC 服务器时，近端用 VNC 查看器（macOS 上是“屏幕共享”）打开，否则用浏览器打开。

## 直连

直连是按主机自己的地址（它的 ssh 配置里的 `HostName`）直接打开主机的一个端口，不经端口转发。它适用于可以这样直接访问的主机，也不需要主连接。

“直连”分区标题上的 + 添加一个并立即打开。此后点一下就能用：单击它的行打开这个端口，5900 到 5999 之间的端口用 VNC 查看器，其他端口用浏览器。× 移除它。

## 主机自己的端口

“主机上的端口”下面是主机端口：主机自己监听的端口。

一开始，这个分区列出 VNC 服务器：

- Xvnc、Xtigervnc、x11vnc 之类；
- 在 Mac 上，是它的“屏幕共享”或“远程管理”。它们的 5900 端口由 launchd 以 root 身份持有，所以只有 `launchctl` 能判断它是否开着。

分区标题上的 + 再添加一个端口：

- 这个账户看得到的监听端口之一（`ss`，macOS 上是 `lsof`），主机给出程序名时一并显示。`ss` 只给出用户自己的监听端口的程序名，`lsof` 则根本只列出用户自己的；
- 或者手动输入任意端口（“其他端口…”），用于账户看不到的那些。

5900 到 5999 之间的端口，如果没有别的信息说明它是什么，就当作 VNC。

| 控制项 | 作用 |
|---|---|
| 单击这一行 | 经由一条通向它的 `-L` 转发在本机打开这个端口。没有转发时当场建立一条，并和其他转发一起留在端口转发分区里。 |
| 地球 | 改为按主机自己的地址（它的 ssh 配置里的 `HostName`）打开这个端口，不经端口转发，适用于可以这样直接访问的主机。 |
| × | 把这个端口从列表里移除。 |

在[本机的控制台](console.md)里，这个面板只有一个分区“本机上的端口”：本机的监听端口，直接在 `127.0.0.1` 上打开，不经端口转发。

## 这些行保存在哪里

你设置的内容按主机保存在本机。

端口转发和直连同样列在[主窗口](main-window.md)的工具卡片里，在控制台和文件两个按钮下面：是同样的几行，这样不开控制台也能点一下就打开端口。工具卡片标题上的 + 添加一条端口转发（“新建隧道…”）或一个直连（“直连…”）。
