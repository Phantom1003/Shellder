# 控制台

控制台是一台主机的窗口，里面是各项读数和终端。它显示主机正在做什么（负载、内存、磁盘、进程），还有主机的文件、tmux 和 screen 会话、作业、容器和端口；这些内容旁边是开在主机上的终端，放在标签页里。同一个窗口可以在主机之间切换，本机也有自己的控制台。

## 打开控制台

每台主机都有自己的控制台窗口。入口有四个：

- [主机行](main-window.md)上的控制台按钮，指针移到这一行时出现（界面上目前写作“监控台”）。
- 在主窗口里按 `⌘T`，打开所选主机的控制台。
- 主机页工具卡片里的控制台按钮，在“文件”按钮旁边。
- 菜单栏菜单的主机子菜单：“Console”，旁边还有“Shell”和“Files”（菜单栏菜单目前只有英文）。

窗口打开时，第一个终端标签页里是主机上的一个 shell。

## 三个区域

窗口由顶栏、左边的侧栏和右边的标签区组成。

| 区域 | 内容 |
|---|---|
| **顶栏** | 左端是主机菜单（主机名），右端是设置按钮（齿轮）。顶栏的其余部分可以拖动窗口。 |
| **侧栏** | 面板切换条（窗口左边缘的一竖条图标），以及它旁边一次显示一个的面板。 |
| **标签区** | 一个分组，或分栏出来的几个分组。每个分组有自己的标签栏，显示其中一个标签页：终端或预览。 |

设置按钮打开控制台设置窗口（`⌘,`），见[控制台设置](console-settings.md)。标签区另有专页：[标签页、分组与分栏](console-tabs.md)和[终端内部](console-terminals.md)。

## 侧栏与面板

面板切换条上的每个面板按钮显示对应的面板，按钮的悬停提示就是面板的名字。显示哪个面板按主机保存在本机。

| 面板 | 显示什么 |
|---|---|
| [状态面板](console-status.md) | 主机的各项读数，分成卡片：运行时间和负载、CPU、内存和交换区、GPU、磁盘、网络、进程、登录的用户。 |
| [文件面板](console-files.md) | 主机的文件树，带复制状态条。 |
| [会话面板](console-sessions.md) | 主机上的 tmux 和 screen 会话。 |
| [作业面板](console-sessions.md) | 你的 Slurm 和 PBS 作业。只有主机上装了 Slurm 或 PBS 客户端，才有这个面板按钮。 |
| [容器面板](console-sessions.md) | Docker 或 Podman 容器。只有主机上有 Docker 或 Podman，才有这个面板按钮。 |
| [端口面板](console-ports.md) | 端口转发、直连和主机自己的端口。 |

### 折叠侧栏

侧栏可以像编辑器的侧栏那样折叠起来，只留面板切换条，窗口让给标签区。下面任何一种操作都会折叠它：

- 点击当前面板的面板按钮；
- 按 `⌘⇧S`；
- 把侧栏的边缘拖到远小于最小宽度的位置。

点击任意面板按钮、再按一次 `⌘⇧S` 或把边缘拖回来，侧栏就重新展开。侧栏是否折叠保存在本机。

### 侧栏访问

不用指针，也可以把键盘焦点移进侧栏再移回来。

| 快捷键 | 作用 |
|---|---|
| `⌘⇧L`，或在最左边的分组里按 `⌘⌥←` | 键盘焦点进入侧栏。 |
| 再按 `⌘⇧L`、`⌘⌥→`、`Esc` | 键盘焦点回到原来的标签页。 |
| `Tab`、`⇧Tab` | 下一个、上一个面板。 |
| `↑`、`↓` | 在会话、作业、容器和端口面板的各行之间移动。 |
| `↩` | 相当于单击这一行。 |
| `⇧↩` | 相当于双击这一行（会话的标签页会被固定）。 |

在文件面板里，文件树有自己的快捷键，包括方向键和 `↩`，见[文件面板](console-files.md)。

折叠的侧栏会为这次访问临时展开，键盘焦点离开后再折叠回去。某一行打开了标签页之后，焦点会自己离开：新标签页拿走键盘焦点。在[沉浸模式](console-window.md)下窗口不显示侧栏，这时在最左边的分组里按 `⌘⌥←`，或按 `⌘⇧L`、`⌘⇧S`，同样会让侧栏出来接受一次访问，并随键盘焦点一起收回。

以上是 macOS 上的默认快捷键；Linux 上的默认是 Ctrl+Shift 的组合。它们都可以修改，见[快捷键](keys.md)。

## 把窗口切换到另一台主机

主机菜单最前面是本机（标签为“本机”），后面是主机列表里的每台主机，各带状态点的颜色。窗口当前显示的主机前面有勾。

选中一台主机，窗口就切换过去，位置和大小都不变：

- 侧栏读取新主机；按主机保存的内容（显示哪个面板、选了哪些卡片）也换成新主机的。
- 新的标签页开在新主机上。
- 已经打开的标签页保持原样，各自留在它运行的主机上。如果标签页运行的主机不是窗口当前显示的主机，它的开头会标出主机名。
- 已经有控制台窗口的主机不会显示两次：这时会把那个窗口调到前面。

用键盘做同样的切换，见[主机轮盘](console-window.md)。

## 本机的控制台

切换到“本机”之后，控制台就是这台电脑自己的：

- 状态面板读取本机，方式和读取主机一样。
- 文件面板是本机自己的文件树。没有上传和下载可言；拖动仍然可以复制到某台主机的控制台或文件窗口。
- 会话面板列出本机上运行的 tmux 和 screen 会话。
- 端口面板列出本机的监听端口，直接在 `127.0.0.1` 上打开，不经端口转发。
- 新标签页是你的登录 shell，启动方式和终端应用一样，中间没有 ssh。

状态面板里需要密码的命令（比如向别的账户的进程发信号）会在[提示窗口](prompt-window.md)里提问，和在主机上一样。

## 读数是怎么得到的

读数来自在主机上运行的一个 shell 脚本。

- 在 Linux 上，它用到 `/proc`、`df -P`、`ps`、`who`、`ss`、`ip`、`tmux list-sessions`、`screen -ls`、`docker ps`、`squeue` 和 `qstat -f`。
- macOS 主机则通过 `sysctl`、`vm_stat`、`top`、`netstat`、`ifconfig` 和 `lsof` 回答。

脚本里只包含状态面板上正在显示的部分，所以用卡片选择关掉的卡片不会给主机带来任何开销。

登录的用户取自 `who`，也就是 utmp。不保留 utmp 的 Linux（Ubuntu 26.04 只把登录记在 systemd-logind 里）改用 `loginctl` 回答。两者的计数并不相同：utmp 是每个终端一行；logind 是每条 ssh 连接一个会话，不管它带了多少个终端，没有终端的连接也算一个。Shellder 自己到主机的主连接就属于后一种。

## 不需要主连接

控制台和[文件窗口](files-window.md)都不依赖主连接。主连接已建立时，它们走主连接，不需要再登录；否则它们自己登录（见[没有套接字时](without-a-socket.md)）。

这次登录和主连接的登录一样：ssh 在只有 Shellder 读取的控制终端上提问，回答来自[钥匙串](keychain.md)或[提示窗口](prompt-window.md)。在控制台的终端里输入的内容，绝不会进入这次登录的密码提问。
