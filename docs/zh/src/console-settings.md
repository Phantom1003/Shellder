# 控制台设置

终端有自己的设置窗口，即控制台设置窗口（标题目前写作“监控台设置”），和应用的[设置窗口](settings.md)是分开的。设置按钮（顶栏右端的齿轮）可以打开它，在控制台里按 ⌘, 也可以。里面的设置属于整个应用：每个控制台窗口都一样，改动会立刻作用到已经打开的终端。窗口顶部的页栏在五个页之间切换：“终端”“行为”“快捷终端”“主题”和“快捷键”。窗口打开时显示上次看的那一页。

## 终端

终端的外观。

| 行 | 设置的内容 |
| --- | --- |
| “字体” | 终端文字的字体族，从本机安装的字体里选。系统的等宽字体（Mac 上是 SF Mono）排在最前面，是默认值；然后是等宽字体，再后面是其余字体。字号不在这里：在控制台里用 ⌘+ 和 ⌘− 调整 |
| “行高” | 一行的高度，从 1 到 2 |
| “光标” | 光标的形状：“方块”“竖线”或“下划线” |
| “光标闪烁” | 光标是否闪烁 |
| “回滚” | 终端保留多少行历史输出 |
| “配色（浅色）” | 浅色终端用的配色 |
| “配色（深色）” | 深色终端用的配色 |
| “不透明度” | 窗口有多透明，一个滑块 |
| “背景模糊” | 窗口后面的内容模糊到什么程度（仅 macOS） |
| “内边距” | 终端四周留的空白，指左右两侧，单位是像素 |

**配色。** 两个配色行各自可以选：窗口自带的两套颜色（“默认”）、内置配色（Solarized、One、GitHub、Catppuccin、Gruvbox、Tokyo Night、Nord、Dracula）和你的主题文件。分组的[背景按钮](console-tabs.md)就是在这里选定的两套配色之间切换。“主题”页选的也是这两套配色，同时能看到它们的颜色。

**不透明度。** 滑块移动时控制台窗口随之变化：它们本来就是透明窗口，所以不透明度同时作用到所有窗口。顶栏、侧栏和终端一起变，和 Ghostty 的 `background-opacity` 一样。

**背景模糊。** 关闭加五档，每档一个刻度，左端清晰，右端模糊。它是窗口服务器自己对背景做的模糊，和 Ghostty、iTerm2 一样，只对透明的窗口起作用。默认关闭，要用才开，因为模糊每一帧都要重画，可能让打字显得迟钝。

**内边距。** 上下方向，网格只有整数行排完之后剩下的空间，上下各分一半。列排完剩下的空间也这样左右平分，加在内边距之外。[沉浸模式](console-window.md)下的窗口完全没有内边距。

## 行为

终端的行为。

| 行 | 设置的内容 | 默认 |
| --- | --- | --- |
| “选中即复制” | 选中的内容随选随复制 | 关 |
| “粘贴多行前先询问” | 粘贴确认 | 开 |
| “关闭仍有命令运行的标签前先询问” | 关闭仍有命令在运行的标签页或窗口之前的询问（需要 Shell 集成） | 开 |
| “响铃” | 终端在屏幕上时终端响铃的表现：“闪一下”“声音”“闪一下并发声”或“都不” | “闪一下” |
| “声音”（“响铃”下面） | 终端响铃播放哪个声音：系统提示音、系统的其他声音，或你自己的文件；▶ 试听。响铃会发声时才显示这一行 | 系统提示音 |
| “通知” | 没人在看的标签页里发生的事是否以系统通知告知 | 开 |
| “声音”（“通知”下面） | 系统通知附带的声音，选法相同 | “无” |
| “Shell 集成” | 从控制台启动的 shell 是否得到 Shell 集成 | 开 |
| “使用 WebGL 绘制” | 终端用 WebGL 绘制，而不是 DOM 渲染器 | 关 |

粘贴确认、终端响铃、系统通知和 Shell 集成的说明见[终端](console-terminals.md)。

**WebGL。** DOM 渲染器让 WebKit 自己绘制文字，在 Mac 上比 WebGL 的字形图集好看。WebGL 在满屏输出时更快，所以觉得 `cat` 或 `htop` 慢的时候可以试试。

## 快捷终端

[快捷终端](console-window.md)的快捷键和主机。

| 行 | 设置的内容 |
| --- | --- |
| 快捷键（界面上写作“按键”） | 在任何应用里让快捷终端从屏幕顶部滑下来的快捷键。点击输入框，再按下要用的键，其中要有一个修饰键。⌫ 或输入框旁边的 × 取消这个快捷键 |
| “主机” | 快捷终端的 shell 开在哪台主机上，或者本机 |

应用拿不到的键（被系统或其他应用占用）会在这一行下面说明，并给出原因。

## 主题

各个配色并排显示：左边是列表，右边是选中的配色。

### 列表

- 顶部的开关，“浅色”或“深色”，表示正在为哪一边选择：浅色终端的配色，还是深色终端的。
- 下面是各个配色：窗口自带的颜色（“默认”）、内置配色和你的主题文件，每个带一个色样。这一边当前用的配色有标记。
- 点击某个配色，就为这一边选中它，已经打开的终端随之变化。
- 在配色上按右键，有“用于浅色终端”“用于深色终端”、创建副本（界面上写作“复制…”），主题文件还有“重命名…”和“删除此主题文件”。
- 列表下方的“打开主题文件夹”打开存放主题文件的文件夹。

### 选中的配色

- 一个用这套配色画出的示例终端。
- 这套配色设置的每一种颜色：背景、前景、光标、光标下的文字、选区和选中的文字，然后是程序按名字使用的十六种颜色（palette 0 到 15）。
- 每种颜色显示它的值；配色没有设置它时，显示它回退到什么：光标回退到前景色，选区回退到强调色，没设置的颜色回退到 xterm 自己的。
- 每种颜色有一个取色框用来修改它。

取色框的效果取决于配色的种类：

| 配色 | 在取色框里改颜色 |
| --- | --- |
| 主题文件 | 立刻生效：文件里对应的那一行被替换，其余内容不动。文件自己设置的颜色旁边有 ×，点它把那一行去掉 |
| 内置配色，或“默认” | 不会被修改。创建副本（按钮写作“复制”）会生成一个主题文件，名字由你定，并为这一边选中它，取色框改的是这个副本 |

创建副本按钮旁边的铅笔和垃圾桶用来重命名和删除主题文件。内置配色没有这两个按钮。

### 主题文件

主题文件放在一个文件夹里（状态目录下的 `themes`），每个配色一个文件，用的是 Ghostty 的格式：

```
# a comment
background = 1d1f21
foreground = c5c8c6
palette = 0=#1d1f21
```

- `palette` 行从 0 到 15。
- 文件里有 `cursor-color`、`cursor-text`、`selection-background` 和 `selection-foreground` 时也会读取。
- 以 `#` 开头的行是注释。

Ghostty 自带的主题和 iTerm2-Color-Schemes 的 Ghostty 导出文件可以原样放进去，名字就是文件名。放进文件夹的文件，或在编辑器里改过的文件，在窗口回到前台时出现在列表里；被选中时作用到终端。

## 快捷键

控制台的快捷键，按分区排列，每个键是一个快捷键标签。默认值列在[快捷键](keys.md)里。

| 要做的事 | 做法 |
| --- | --- |
| 修改一个快捷键 | 点击它的快捷键标签，再按下要改用的键 |
| 中止修改 | 按 Esc |
| 去掉一个快捷键 | 点击快捷键标签上的 × |
| 给动作再加一个快捷键 | 点击这一行的 + |
| 恢复一行的默认值 | 点击行尾的箭头 |
| 全部恢复默认 | 点击“全部恢复默认” |

两个动作共用的键会被标出，列表里靠前的动作得到它。快捷键保存在本机，对每个控制台窗口都有效。
