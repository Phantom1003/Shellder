# 会话、作业与容器

侧栏里有三个面板，列出主机上可以开终端进去的东西：会话面板是 tmux 和 screen 会话，作业面板是你的 Slurm 和 PBS 作业，容器面板是 Docker 或 Podman 容器。点击一行，就在终端标签页里打开它；如果它已经开在某个标签页里，就把那个标签页调出来。

## 会话面板

主机上有哪种工具，面板里就有它的一个分区，先是 tmux，然后是 GNU screen。每个分区标题上有一个用来新建会话的 +，下面每个会话占一个会话行。

### 会话行

tmux 的会话行显示会话的名字、有几个窗口、有几个客户端连着、最近一次活动的时间，并为每个窗口显示一个窗口标记。screen 的会话行显示会话的名字、pid，以及是否有客户端连着。

每一行还显示会话的当前目录。tmux 取的是活动窗口的目录；screen 取的是其中 shell 的目录，从 `/proc` 读出，所以只在 Linux 上有。

| 控制项 | 作用 |
|---|---|
| 单击这一行 | 在临时标签页里连接这个会话（`tmux attach`、`screen -x`）；已经开在某个标签页里时，调出那个标签页。 |
| 双击这一行 | 在固定标签页里连接这个会话。 |
| 文件夹按钮 | 在[文件面板](console-files.md)里显示会话的目录。 |
| 终端按钮 | 在这个目录里打开主机的一个 shell，标签页以目录命名。 |
| 铅笔 | 给会话改名（`tmux rename-session`、`screen -X sessionname`）。 |
| 叉号 | 确认之后结束会话，连同里面的一切（`tmux kill-session`、`screen -X quit`）。 |

### 临时标签页和固定标签页

会话的打开方式和文件面板里的文件一样：

- 单击使用键盘焦点所在分组的临时标签页，它的名字是斜体。
- 再单击另一个会话，就顶替这个标签页。里面的客户端断开，原先显示的会话继续存在。
- 双击这一行，或双击标签页本身，就把标签页固定下来。

关闭会话标签页只是断开客户端。关于标签页的更多内容，见[标签页、分组与分栏](console-tabs.md)。

### 新建会话

tmux 或 screen 分区标题上的 + 打开新建会话对话框。它问三项内容，都可以不填：

| 字段 | 含义 |
|---|---|
| “名称” | 会话的名字。不填时由工具给会话编号。 |
| “目录” | 会话启动时所在的目录；不填就是主目录。文件夹按钮打开文件夹选择器，从主机的文件夹树里选一个（对“本机”则是系统自己的文件夹对话框）。 |
| “命令” | 在会话里代替 shell 运行的命令。命令结束，会话也就结束；写成 `cmd; exec $SHELL` 可以在命令之后留下一个 shell。 |

“打开”建立会话，并在一个新标签页里连接它。

## 作业面板

主机上有 Slurm 或 PBS 客户端时才有作业面板。它列出你的作业，每个作业一个作业行。

| 作业 | 单击打开 |
|---|---|
| 运行中的 Slurm 作业 | 作业节点上的一个 shell（`srun --jobid … --overlap --pty bash`）。 |
| 运行中的 PBS 作业 | 作业第一个节点上的一个 shell（从登录节点 `ssh` 过去）。 |
| 排队中的作业 | 什么也不打开：只有运行中的作业可以进入。 |

每个作业行都显示作业的工作目录（Slurm 的 `WorkDir`、PBS 的 `PBS_O_WORKDIR`），排队中的作业也一样，并带有和会话行相同的文件夹按钮和终端按钮。

面板标题上的 + 在标签页里开一个交互式作业：Slurm 是 `srun --pty bash`，PBS 是 `qsub -I`。主机上两种调度器都有时，+ 打开一个二选一的菜单。

## 容器面板

主机上有 Docker 或 Podman 时才有容器面板。它列出容器，每个容器一个容器行。单击一行，就在容器里打开一个 shell（`docker exec -it`）。

容器的绑定挂载按主机一侧的路径列在它的行上，并带有文件夹按钮和终端按钮：文件夹按钮在文件面板里显示这个目录，终端按钮在主机上的这个目录里打开一个 shell。绑定挂载有多个时，两个按钮各打开一个菜单供选择。
