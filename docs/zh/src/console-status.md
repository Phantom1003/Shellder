# 状态面板

状态面板用卡片显示主机正在做什么：运行时间和负载、CPU、内存和交换区、GPU、磁盘、网络、最忙的进程，以及登录的用户。读数每隔几秒重新读取一次。有些卡片还能对主机做操作：添加交换区、挂载和弹出可移动驱动器、向进程发信号。

## 概况卡片

第一张卡片给出主机的名字和概况：主机名、系统和内核、已经运行多久、平均负载、CPU 数量和登录数。

## 用量卡片

用量卡片（界面上目前的标题是“占用”）里，CPU、内存和交换区各有一个用量条：一个名称、一个数值和一根随之填充的条。到 70 % 时条变成橙色，到 90 % 时变成红色。

卡片标题上是整个面板的控制项：

| 控制项 | 作用 |
|---|---|
| 刷新间隔 | 多久读取一次：“每 2 秒”“每 5 秒”“每 10 秒”或“每 30 秒”。保存在本机。 |
| 卡片选择（眼睛） | 显示哪些卡片：“CPU”“内存与交换区”“GPU”“磁盘”“网络”“进程”“已登录”。菜单不会关上，可以接着选下一项。按主机保存在本机。 |
| 刷新按钮 | 立即读取。在窗口里任何地方按 `⌘R` 也一样。 |

关掉的卡片也不再读取，主机就省下了相应的命令：macOS 上 `top` 的一秒采样、`nvidia-smi`、等在失效网络挂载上的 `df`、`ps` 及其排序。主机响应慢，或者正忙着别的事时，这一点很有用。

读取失败时，面板不显示卡片，而是显示错误信息和“重试”按钮；在你按下它或主机的主连接恢复之前，不再读取。

### 单位

- 内存、交换区和 GPU 显存用二进制单位（GiB，以 1024 为基数），与内核和系统自带工具的算法一致。
- 磁盘、文件和网络流量用十进制单位（GB），与访达和硬盘厂商的算法一致。

### 添加和删除交换文件

在 Linux 主机上，“交换区”用量条上有一个 +，用来添加交换文件。它会询问大小（GiB）和文件路径。

- 文件用 `fallocate`（文件系统不允许在这种文件上做交换时用 `dd`）、`mkswap` 和 `swapon` 建立。
- 下次重启后它就没有了：不会往 fstab 里写任何东西。
- 文件是 `/shellder.swap`。名字已被占用时加上编号（`/shellder.swap2`、`3`……），所以可以添加多个。
- 文件名里带有“shellder”。状态面板就是凭这一点把它和主机自己的交换区区分开。

这样添加的每个交换文件都列在“交换区”用量条下面，各带一个按钮：确认之后关闭并删除它。里面的内容会先回到内存。

这两种操作主机都要求 root 权限。账户有免密码的 `sudo` 时直接使用；否则 `sudo` 会要密码，这个提问和 ssh 自己的提问一样，转到[提示窗口](prompt-window.md)（见下文“主机要密码时”）。

## GPU 卡片

主机上有 `nvidia-smi` 时，每块 GPU 显示名称、一个“负载”用量条和一个“内存”用量条。

## 磁盘卡片

每个已挂载的磁盘有一个用量条：挂载点、剩余空间、设备，以及总容量中已用多少。双击一个磁盘，就在[文件面板](console-files.md)里显示它。

### 可移动驱动器

可移动驱动器（U 盘、存储卡、光盘；由 `lsblk` 判断，macOS 上是 `diskutil`）上的卷有两个按钮：

| 按钮 | 作用 |
|---|---|
| 卸载 | 卸载这个卷。 |
| 弹出 | 卸载驱动器上的所有卷并给它断电，之后可以拔下。 |

驱动器上没有挂载的卷列在磁盘下面，各带一个挂载按钮。

在 Linux 上，操作按下面的顺序依次尝试三种办法，主机的回答会显示出来：

1. udisks（`udisksctl`）；
2. 普通的 `mount` 或 `umount`（fstab 条目带 `user` 选项）；
3. `sudo -n`，前提是账户有免密码的 `sudo`。

udisks 允许坐在主机本地控制台前的用户挂载和断电。ssh 会话不算本地控制台，所以经由 ssh 时 udisks 会去问 polkit，而 polkit 要管理员密码。卸载你自己挂载的卷不需要密码。

### 主机要密码时

如果主机要了密码（polkit 或 `sudo` 的）才肯执行，Shellder 会在自己的一个终端上把操作再运行一次，主机在上面的提问按回答 ssh 提问的办法回答：

- 为这台主机保存了密码、主机也接受时，用保存的密码；
- 否则在[提示窗口](prompt-window.md)里问你。窗口在提问原文上方写明是什么操作（`mount /dev/sdb1`、`kill -TERM 1234`）。在那里输入的密码可以保存为这台主机的密码。

取消提问就结束这次操作。不会有任何东西在标签页里打开。

### 免去提问

在主机上加一条 polkit 规则，放行账户所在的组（这里是 `plugdev`），就不会再有这个提问：

```
# /etc/polkit-1/rules.d/50-mount-over-ssh.rules
polkit.addRule(function (action, subject) {
    if ((action.id == "org.freedesktop.udisks2.filesystem-mount" ||
         action.id == "org.freedesktop.udisks2.filesystem-unmount-others" ||
         action.id == "org.freedesktop.udisks2.eject-media" ||
         action.id == "org.freedesktop.udisks2.power-off-drive") &&
        subject.isInGroup("plugdev"))
        return polkit.Result.YES;
});
```

没有这样的规则时，给这个卷写一条带 `user` 的 fstab 条目，或者让 `mount`、`umount` 和 `eject` 可以免密码 `sudo`，效果相同。

## 网络卡片

网络卡片列出有地址的网络接口：IPv4 和全局 IPv6 地址，不含回环接口，也不含链路本地地址。每一行显示接口的地址，以及自上一次读数以来每秒收到和发出的数据量。

数字来自主机的计数器：`/proc/net/dev`，macOS 和各种 BSD 上是 `netstat -ibn`。地址来自 `ip -o addr` 或 `ifconfig`。

## 进程卡片

进程卡片要么是最忙进程表，要么是进程树。卡片标题上的按钮在两者之间切换，选择保存在本机。

### 最忙进程表

表里是 CPU 占用最高的二十个进程和内存占用最高的二十个进程，列为“PID”“用户”“CPU %”“内存 %”和“命令”。

| 操作 | 作用 |
|---|---|
| 点击列标题 | 按这一列排序；再点一次反向排序。保存在本机。 |
| 点击单元格 | 复制单元格的完整内容：是被列宽截断的整条命令行，而不是整行。 |
| 右键点击一行 | 打开信号菜单。 |

### 信号菜单

信号菜单列出可以发给这个进程的信号：“终止 (SIGTERM)”“强制结束 (SIGKILL)”“中断 (SIGINT)”“挂断 (SIGHUP)”“暂停 (SIGSTOP)”或“继续 (SIGCONT)”。发送之前有一个对话框要你确认。

信号以当前账户的身份用 `kill` 发送；发给其他用户的进程时经由 `sudo`，要密码的方式和挂载时一样（见上文“主机要密码时”）。

### 进程树

进程树显示窗口当前标签页下面的进程。它以什么为根，取决于这个标签页：

| 当前标签页 | 进程树显示 |
|---|---|
| tmux 的会话标签页 | 这个 tmux 会话的各个窗格。 |
| screen 的会话标签页 | 这个 screen 会话。 |
| 容器标签页 | 这个容器，前提是主机的 `ps` 能看到容器里的进程（Docker Desktop 上不行）。 |
| shell 标签页，或其他任何标签页 | 当前账户的 ssh 登录：`sshd` 会话进程下面的各个 shell，以及它们运行的一切。控制台自己读取读数的进程不算在内。 |

进程树以什么为根，写在卡片标题的悬停提示里。

进程树和最忙进程表有几点不同：

- 没有用户列。进程的用户和父进程不同时（比如 `sudo`），在命令前面标出这个用户。
- 命令只显示程序名，不带目录。悬停提示和复制给出的是完整内容。
- 顺序是固定的，列标题不能排序。

进程树跟随所选的标签页，每次读数时读取它，代替最忙的进程。和表里一样，点击单元格是复制，信号菜单提供同样的信号。

## 已登录卡片

已登录卡片里每次登录占一行：用户、终端、登录时间和来源。这份列表从哪里来、为什么不同主机上的计数不一样，见[控制台](console.md)。
