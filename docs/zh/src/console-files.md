# 文件面板与预览

文件面板是控制台侧栏里显示主机文件的面板：上面是文件工具栏，中间是带列标题的文件树，底部是路径栏，再往下是复制状态条。单击一个文件，它会在标签区的预览标签页里显示出来，与终端并排。[文件窗口](files-window.md)的每个窗格里画的是同一棵文件树；本页完整描述它，那一页只讲不同之处。

{{#include figures/console-files.html}}

## 面板显示什么

面板显示主机上的一个文件夹（下文称“当前文件夹”），以及在它下面展开的内容。打开时显示的是账户的主目录；主机上有 `~/Shellder` 文件夹时，显示这个文件夹。

控制台的其他部分可以让面板转到某个文件夹：

- 在[状态面板](console-status.md)里双击一个磁盘；
- 会话行、作业行或容器行上的文件夹按钮（见[会话、作业与容器](console-sessions.md)）；
- 在终端里按住 ⌘ 点击路径链接（见[终端内部](console-terminals.md)）。

窗口显示过的每台主机，控制台都为它保留一个文件面板，所以窗口切换到别的主机再切回来，文件树还是原来的样子。窗口显示本机时，面板就是本机自己的文件树：没有可上传或下载的东西，也没有文件窗口按钮，但从这里拖出的文件行仍然可以复制到某台主机的控制台或文件窗口。

## 文件工具栏

文件树上方的按钮，从左到右。每个都是图标，这里给出的名字是它的悬停提示。

| 按钮 | 作用 |
|---|---|
| “前往 … 上的某个文件夹” | 打开文件夹选择器（见下文“文件夹选择器”）。 |
| “新建文件夹” | 询问名称并新建一个文件夹（见下文“新建文件夹和文件”）。 |
| “新建文件” | 询问名称并新建一个空文件。 |
| “删除” | 询问之后删除选中的项。没有选中任何项时不可用。在本机上它显示为“移到废纸篓”。 |
| “显示以点开头的条目” | 显示或隐藏隐藏文件。 |
| “回到上一个目录” | 回到之前显示的文件夹。没有可回的文件夹时不可用。 |
| “上一级目录” | 显示当前文件夹的上一级。 |
| “刷新” | 重新读取当前文件夹，以及它下面所有展开的文件夹。 |
| 最后一个按钮（链接图标） | 打开文件窗口，并让它显示面板的当前文件夹（见下文“在文件窗口中打开”）。本机没有这个按钮。 |

## 文件树

### 列标题与排序

列标题是“名称”“修改日期”和“大小”。点击其中一个，文件树按这一列排序；再点一次，顺序反过来。列标题旁边的排序箭头（↑ 或 ↓）表示方向。按名称排序时，文件夹排在前面。按日期或大小排序时，文件夹和文件混排，所以最近改过的或最大的那一项总在最上面，不管它是什么。排序方式保存在本机。

侧栏比较窄，所以文件面板里的日期不带时间；完整的日期在悬停提示里。

### 文件行与文件夹

文件夹里的每一项是一个文件行：图标、名称、日期和大小。

- 文件夹左边的**展开箭头**在树里就地展开或收起这个文件夹。
- **双击**文件夹进入它：它成为当前文件夹。
- 指针移到文件夹所在的行上时，行的右端会出现一个按钮（“收起里面的所有文件夹”），它把这个文件夹里展开的所有文件夹都收起来。

每个显示过的文件夹，在面板转去显示别的文件夹期间，都保留自己这棵树的形状。通过双击、“返回”或“上一级目录”再次进入时，它里面的文件夹仍像离开时那样展开着，滚动位置也不变；经“返回”或“上一级目录”回来时，刚离开的那个文件夹处于选中状态。

### 选择与点击

| 操作 | 作用 |
|---|---|
| 单击文件 | 选中它，并在拥有键盘焦点的分组的临时预览标签页里显示它（见下文“预览标签页”）。键盘焦点留在文件树里。 |
| 双击文件 | 在固定的预览标签页里显示它。 |
| 单击文件夹 | 选中它。只有展开箭头才会展开它。 |
| 按住 ⇧ 点击 | 选中从上次点击的行到这一行之间的所有行。 |
| 按住 ⌘ 点击 | 把这一行加入选择，或从选择中去掉。 |
| 在多个选中的行里单击其中一行 | 只留下这一行被选中。 |
| 单击各行下方的空白处 | 取消所有选择。 |

键盘焦点在文件树里时：`↑` 和 `↓` 移动选择，`→` 展开选中的文件夹，`←` 收起它，`↩` 进入文件夹或在固定的预览标签页里显示文件，`⌘⌫` 在询问之后删除选中的项。`⌘⇧L` 把键盘焦点移进侧栏再移回来（见[控制台](console.md)）。

## 路径栏

文件树底部的路径栏是当前文件夹的路径，每一段都是按钮：第一段是根目录（`/`，在本机上标为“本机”），最后一段是当前文件夹。点击某一段就显示那个文件夹；点击最后一段则重新读取当前文件夹。名称太长时会被截短，完整路径在悬停提示里。

## 文件夹选择器

文件工具栏的“前往 … 上的某个文件夹”和空白处右键菜单里的“前往文件夹…”都会打开文件夹选择器：

- 最上面是一个输入框，里面是路径。修改后按回车就前往那里；按 Esc 关闭选择器。在输入框里输入另一个路径，下方就显示那个路径的树。
- 输入框旁边的“上一级目录”和“主目录”移动选择器里的树。
- 下方是该路径下各文件夹组成的树。文件夹用展开箭头展开，点击文件夹名称就让面板显示它。里面没有文件夹的，显示“里面没有文件夹”。

## 右键菜单

右键菜单里有文件工具栏上的全部功能，还多几项。在未选中的行上点右键，会先选中它；在已选中的行上点右键，菜单作用于所有选中的项。

### 文件行上

| 菜单项 | 何时出现 | 作用 |
|---|---|---|
| “打开” | 单个文件夹 | 进入这个文件夹。 |
| “预览” | 单个文件 | 在固定的预览标签页里显示这个文件。 |
| “上传到这里…” | 单个文件夹 | 把在本机上选取的文件复制到这个文件夹里。 |
| “在此打开 shell” | 单个文件夹 | 打开一个 shell 标签页，shell 从这个文件夹启动。 |
| “下载…”（“下载 n 项…”） | 任意选择 | 把选中的项复制到在本机上选取的文件夹里。 |
| “新建文件夹…”“新建文件…” | 任意 | 建在所点的文件夹里，或所点文件的旁边。 |
| “重命名…” | 单独一行 | 就地给这一项换个名字。 |
| “删除…” | 任意选择 | 询问之后删除选中的项。 |
| “刷新” | 任意 | 与工具栏上的相同。 |

### 空白处

针对当前文件夹：

| 菜单项 | 作用 |
|---|---|
| “上传到这里…” | 把在本机上选取的文件复制到当前文件夹里。 |
| “在此打开 shell” | 打开一个 shell 标签页，shell 从当前文件夹启动。 |
| “新建文件夹…”“新建文件…” | 建在当前文件夹里。 |
| “前往文件夹…” | 打开文件夹选择器。 |
| “返回”“上一级目录” | 与工具栏上的相同。 |
| “显示隐藏文件” / “不显示隐藏文件” | 与工具栏上的眼睛按钮相同。 |
| “刷新” | 与工具栏上的相同。 |
| “在文件窗口中打开” | 与工具栏的最后一个按钮相同。 |

在本机上，菜单里没有“上传到这里…”“下载…”和“在文件窗口中打开”。

## 新建文件夹和文件

“新建文件夹”和“新建文件”在对话框里询问名称，对话框会说明新建的项放在哪里（“将建在 …”）：选中的是文件夹，就建在它里面；选中的是文件，就建在它所在的文件夹里；什么都没选中，就建在当前文件夹里。从右键菜单新建时，对应的分别是所点的文件夹、所点文件所在的文件夹，以及（在空白处）当前文件夹。

## 重命名

“重命名…”只在单独一行上出现。对话框里先填好现在的名称；如果是文件，扩展名之前的部分处于选中状态，因为重命名时扩展名通常不变。

- 名称已被占用时，重命名被拒绝：不会覆盖任何东西。复制状态条里会说明原因。
- 重命名后的文件夹保持原来的展开状态，这一行也仍然选中。
- 显示这个文件（或被重命名的文件夹里某个文件）的预览标签页会跟着改用新名称。

## 删除

“删除”会先询问（“删除 主机 上的‘名称’？”），并说明此操作无法撤销。在本机上，这一项是“移到废纸篓”，被删的项进入废纸篓（见[文件窗口](files-window.md)）。

## 上传与下载

- “上传到这里…”打开系统的文件选取对话框：在本机上选取的文件被复制到发起上传的那个文件夹里。
- “下载…”打开系统的文件夹选取对话框：选中的项被复制到在本机上选取的文件夹里。

两者都自己指明复制的两端。下载的东西进入选取的文件夹，上传的东西进入发起上传的文件夹：文件窗口的窗格不会因此转到别处。这些复制进入这台主机的队列，并显示在复制状态条里（见下文“复制状态条”）。

## 在此打开 shell，以及把文件行拖到终端上

文件夹的右键菜单和空白处的右键菜单里的“在此打开 shell”，在拥有键盘焦点的分组里打开一个 shell 标签页，shell 从那个文件夹启动。

把文件行拖到终端标签页上，它们的路径会被输入到终端里，需要时加引号，每个路径后面跟一个空格。只有与终端同一台主机的文件行才会被输入。

## 拖入的文件

从桌面拖进来的文件会被复制到主机上：落在文件夹上，就复制到这个文件夹里；落在文件上，就复制到它所在的文件夹里；落在空白处，就复制到当前文件夹里。从另一台机器的文件树（文件窗口的某个窗格，或另一个控制台的文件面板）拖进来的文件行，也按同样的方式复制。

## 在文件窗口中打开

文件工具栏的最后一个按钮，以及空白处右键菜单里的“在文件窗口中打开”，会打开这台主机的[文件窗口](files-window.md)，并让它显示面板的当前文件夹：窗口里显示这台主机的那个窗格转到这个文件夹，在那里按“返回”就回到窗格原来的位置。如果窗口的两个窗格显示的都是别的机器，窗口保持原样。

## 哪些是面板自己的，哪些是共用的

文件树是面板自己的。它显示哪个文件夹、展开了哪些文件夹、选中了什么、按什么排序，都与文件窗口无关，在一处做的任何操作都不会带动另一处。

两者共用的，是属于主机的东西：

- 复制，在两处都列出，连同它们的重名提问；
- 发生了变化的文件夹（多了一个文件、有一项被重命名、有一次复制完成），凡是显示它的地方都会重新读取。

## 复制状态条

复制状态条是文件树下方的那一行（界面上的标签是“传输”）。同一台主机的复制一次只进行一个，其余的在队列里等待。状态条从左到右是：

- 一个箭头，展开和收起复制列表（见下文“复制列表”）；
- 正在进行的复制：表示方向的图标、名称和目的地（`名称 → 文件夹`）、带百分比的进度条（大小未知时是不带百分比的进度条），以及停止它的按钮（“停止这次拷贝”）。被停止的复制已经写入的部分会留下，下一个等待中的复制随即开始；
- 没有复制在进行时，显示最近发生的事：最近完成的那次复制，或一条消息（某一项已删除、一次重命名、一个错误）；
- 等待中的复制个数（“还有 n 个等待”），旁边的 × 把所有等待中的复制移出队列；
- “清空”，把已经结束的复制从复制列表里清掉。

状态条太窄时，会依次省去最不要紧的部分：它的标签、个数旁边的文字、名称（状态条的悬停提示里有），最后是百分比。

## 复制列表

复制列表在复制状态条下方展开，列出这台主机的所有复制，最新的在最上面，最多两百条。拖动它的上边缘可以调整高度。每一行显示复制的状态、名称、从哪里到哪里（`机器:路径 → 机器:路径`），以及下面几种之一：

| 状态 | 含义 |
|---|---|
| “等待中” | 在队列里。行上的 × 把这次复制移出队列。 |
| 进度条 | 正在进行。 |
| 大小和时间 | 已完成。 |
| “已取消” | 被停止，或被移出了队列。 |
| “已跳过，那里已有同名的” | 在重名提问里回答了“跳过”。 |
| 错误信息 | 失败；文字是 sftp 或 scp 的原话。 |

被取消、被跳过或失败的复制，行上有一个按钮可以再做一次：▷（“从停下的地方继续”）或 ↻（“重试”），见下文“继续一次复制”。列表为空时显示“还没有拷贝过任何东西。”

复制属于主机，不属于窗口：控制台或文件窗口关闭后，复制照常进行；Shellder 退出时，复制随之结束。

## 重名提问

复制会覆盖目的地已有的东西，所以每次复制开始之前，Shellder 都先看它要用的名称在目的地是否已被占用；被占用时先问：“替换‘名称’？”

- “替换”覆盖那里已有的项。
- “跳过”不动它；这次复制记为已跳过。
- “应用于全部”把同样的回答用于同一次拖放里剩下的复制。只有这次拖放里还有复制在等待时才提供。

队列会等这个回答。主机的文件面板和文件窗口都会显示重名提问；在一处回答之后，另一处的提问随之消失。

## 继续一次复制

一次中断的复制（被停止，或失败），可以从它自己已经写入的部分继续（▷）：不会再问重名，因为那里有东西正是继续的前提。下面这些则从头开始：

- 当时是在替换一个文件的复制；
- 上传文件夹，或上传一个还没开始写的文件；
- 两台主机之间的复制；
- 开始之前就被移出队列的复制，以及被跳过的复制。它们会重新得到重名提问。

## 预览标签页

{{#include figures/preview.html}}

预览标签页在标签区里显示文件面板里的一个文件，就像编辑器那样。它的顶部是预览标题栏，下面是文件内容。关于标签页的一般说明见[标签页与分组](console-tabs.md)。

### 临时与固定

单击文件，它显示在拥有键盘焦点的分组的临时标签页里。每个分组有一个临时预览标签页，名称是斜体，下一个被单击的文件会顶替它。双击文件（或按回车、选择它菜单里的“预览”、双击标签页本身），它就成为固定标签页。

文件如果已经在这个分组的某个标签页里打开，就直接切到那个标签页。文件如果在另一个分组里打开着，这个分组里也会为它开一个标签页，所以分栏之后可以把同一个文件显示两次。

### 各类文件显示成什么

| 文件类型 | 预览显示什么 |
|---|---|
| 文本 | 原样显示文本，带行号（行号不会被选进选区）。文件名，或没有扩展名的脚本的第一行，能说明是哪种语言时，按语法着色，上限 512 KB。有按钮可以让长行折行、关掉着色。 |
| Markdown（`.md`、`.markdown`） | 渲染后的页面。链接在浏览器里打开；来自网络的图片会显示，相对路径的图片显示为它的替代文字；代码块按围栏标注的语言着色。 |
| 网页（`.html`、`.htm`、`.xhtml`） | 在沙箱化的框架里显示页面：不运行任何脚本，也访问不到自身之外的任何东西。页面自己的样式有效，来自网络的图片会加载。 |
| PDF | 各页上下排列，与标签页同宽。文字可以选中，复制出来是纯文本（扫描的页面没有文字）。复制时一个段落的各行拼成一行，行尾断开的单词接回原样；本身带连字符的词（如“counter-based”），只要所复制的那几页里有它完整出现在行内的地方，连字符就保留。跨栏或跨页的段落同样拼成一行，夹在两半之间的页码不带上。列表的各项、表格的各行和程序的各行仍各占一行。链接可以点击，见下文。 |
| 图片 | 图片本身，适配标签页宽度。 |
| 视频、音频 | 系统的播放器，限于它能解码的格式。 |
| 其他 | 不是文本的文件没有预览，标签页里会这样说明。 |

在 PDF 里，指向文档内部的链接会滚动到它所指的位置，预览标题栏上的箭头（`⌘←`）回到原处；指向网络的链接在浏览器里打开。指针下的链接会被标出，并显示它通向哪里。预览标题栏显示标签页顶部是第几页。

### 预览标题栏

预览标题栏上依次是文件的路径、文件的大小（PDF 还有页码，图片和视频还有像素尺寸，音视频还有时长），然后是适用于当前内容的按钮。每个都是图标，这里给出的名字是它的悬停提示。

| 按钮 | 何时出现 | 作用 |
|---|---|---|
| “回到点链接之前的位置（⌘←）” | PDF，点过文档内的链接之后 | 回到点击链接时的位置。 |
| “在文件中查找（⌘F）” | 文本、Markdown、PDF | 打开查找条（见下文“查找条”）。 |
| “长行折行显示” | 文本 | 让比标签页宽的行折行。 |
| “语法高亮” | 已知语言的文本 | 关闭或打开语法着色。这个选择会被记住。 |
| “显示文件原文，而不是它生成的页面” | Markdown、网页 | 切换到原文视图，或切换回来。 |
| “适配标签页宽度（⌘0）”“适配标签页高度” | 图片、视频、PDF | 适配，见下文。 |
| “双页并排” | PDF | 双页视图。 |
| “缩小”、百分比、“放大” | 除网页和音频之外的所有内容 | 缩放，见下文。 |
| “重新读取” | 全部 | 立即重新读取文件。 |
| “下载到本机的文件夹…” | 主机上的文件 | 见下文“下载文件”。 |

### 原文视图

原文视图把 Markdown 文件或网页按原文显示，而不是显示它生成的页面：显示成文本，带行号和语法着色，文本预览有的功能它都有。

### 适配与缩放

图片、视频或 PDF 可以适配标签页的宽度（`⌘0`，第一个适配按钮）或高度（第二个）。除网页之外的内容都可以这样缩放：

- `⌘+` 和 `⌘−`；
- 按住 ⌘ 滚动滚轮；
- 在触控板上双指捏合（macOS）；
- “缩小”和“放大”按钮。

文本的字号和 Markdown 页面也用同样的方式缩放。用滚轮和捏合时，PDF 的页面以指针所在的点为中心放大和缩小。预览标题栏上的百分比显示当前大小；点击它回到文件的原始大小。

PDF 的各页上下排列；在双页视图里则两页两页并排，适配宽度时每页占标签页宽度的一半。这个选择对所有预览都有效，并会被记住。

### 查找条

`⌘F`，或预览标题栏上的放大镜，在文本、Markdown 页面或 PDF（它的所有页）里打开查找条：

- 所有匹配都被标出，当前这一个更亮，查找条上显示计数；
- `↩` 跳到下一个匹配，`⇧↩` 跳到上一个，与查找条上的箭头相同；
- 输入的文字里有大写字母时，查找区分大小写；
- Esc 关闭查找条。

网页要在它的原文视图里查找。图片、视频和音频没有查找条。终端里的查找条用法相同，见[终端内部](console-terminals.md)。

### 大小上限

文件内容像目录列表一样，经由主机的主连接或它的会话传过来（见[文件窗口](files-window.md)），每类文件各有上限：

| 类型 | 上限 | 超过上限时 |
|---|---|---|
| 文本、Markdown、网页 | 16 MB | 显示开头的 16 MB，并有一行说明。 |
| PDF、图片 | 32 MB | 不显示。 |
| 视频、音频 | 64 MB | 不显示。 |

### 跟随

预览标签页显示在屏幕上的时候，文件处于跟随状态：文件变化后会被重新读取，并画在读者原来所在的位置，在此之前屏幕上一直是旧内容。网页自己的滚动位置不会保留。

文件要连续两次查看都相同才会被重新读取，两次查看在本机上相隔一秒，在主机上相隔两秒半，所以还在写入中的 PDF 不会被读到一半。

### 下载文件

主机上的文件，预览标题栏的最后一个按钮把它下载到在本机上选取的文件夹里：下载的是整个文件，不管标签页里能显示多少，与文件树里的“下载…”相同。这次复制列在那台主机的文件面板的复制列表里。本机上的文件没有这个按钮，[快捷终端](console-window.md)里也没有。
