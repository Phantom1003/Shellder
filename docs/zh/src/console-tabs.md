# 标签页与分组

标签区是控制台的右侧。里面是标签页，每个标签页是一个终端或一个文件的预览；标签页归在分组里，就像编辑器那样：一个分组有一条标签栏，显示它的其中一个标签页；分栏则在它旁边或下面再放一个分组。本页讲标签页和分组本身；终端里面的事见[终端内部](console-terminals.md)，预览显示什么见[文件面板与预览](console-files.md)。

## 标签区

标签区一开始只有一个分组。每个分组有：

- 一条**标签栏**：分组的各个标签页，最后一个标签页后面的新建按钮，以及右端的分组按钮。它们之间的空白处可以拖动窗口。标签页多到放不下时，标签栏可以横向滚动（滚轮也行），新建按钮则移到右端、分组按钮的旁边，所以总能点到；
- 标签栏下面，是当前显示的标签页。

本页的快捷键是 macOS 上的默认值，都可以修改，见[快捷键](keys.md)。

## 标签页的种类

| 种类 | 是什么 | 怎样打开 |
|---|---|---|
| shell 标签页 | 终端标签页，里面是主机上的一个 shell。 | 新建按钮、`⌘T`、文件面板里的“在此打开 shell”、会话行、作业行或容器行上的终端按钮。 |
| 会话标签页 | 终端标签页，连接到一个 tmux 或 screen 会话。 | 在[会话面板](console-sessions.md)里点击会话行。 |
| 作业标签页 | 终端标签页，里面是 Slurm 或 PBS 作业中的一个 shell。 | 作业面板里运行中的作业行，或新建的交互式作业。 |
| 容器标签页 | 终端标签页，里面是容器内的一个 shell。 | 在容器面板里点击容器行。 |
| 预览标签页 | 文件面板里的一个文件。 | 在[文件面板](console-files.md)里点击文件行。 |

shell 设置了标题时，shell 标签页用这个标题作名称，否则以它所在的目录命名。其他终端标签页以它运行的东西命名，预览标签页以文件命名。

## 打开标签页

窗口打开时，第一个终端标签页里是主机上的一个 shell。新建按钮（最后一个标签页后面的 +）或 `⌘T` 在拥有键盘焦点的分组里再开一个 shell 标签页。拥有键盘焦点的 shell 如果报告了自己所在的目录（靠 Shell 集成，见[终端内部](console-terminals.md)），新的 shell 就从那个目录启动，否则从主目录启动。

新的 tmux 或 screen 会话，以及交互式作业，从各自的面板里打开，见[会话、作业与容器](console-sessions.md)。

## 切换标签页

点击标签页就显示它。用键盘：

| 快捷键 | 作用 |
|---|---|
| `⌘1` … `⌘8` | 显示分组里的第几个标签页。 |
| `⌘9` | 显示分组的最后一个标签页。 |
| `⌘⇧]`、`⌃Tab` | 显示分组的下一个标签页。 |
| `⌘⇧[`、`⌃⇧Tab` | 显示分组的上一个标签页。 |

## 临时标签页与固定标签页

单击文件行或会话行，它在临时标签页里打开：这是用来看一眼的标签页，名称是斜体，下一次单击会顶替它。每个分组有一个临时预览标签页和一个临时终端标签页。下一个被单击的会话顶替临时终端标签页时，里面原来的客户端分离，那个会话继续运行。

固定标签页一直留着，直到被关闭。下列情况下标签页是固定的：

- 双击它所在的行来打开（或在文件树里按回车、在文件的菜单里选“预览”）；
- 双击临时标签页本身；
- 在标签页的右键菜单里选“保留此标签页”。

已经在某个标签页里打开的文件或会话，会直接切到那个标签页，不会再开一次。

## 关闭标签页

| 方式 | 关闭什么 |
|---|---|
| 标签页上的 × | 这个标签页。 |
| `⌘W` | 拥有键盘焦点的标签页。没有打开的标签页时，关闭窗口。 |
| `⌘⇧W` | 窗口，任何时候都是。 |
| 标签页右键菜单里的“关闭” | 这个标签页。 |
| “关闭本组中的其他标签页” | 分组里其余的所有标签页。 |

关闭终端标签页就是挂断它的连接。tmux 或 screen 的客户端分离；会话本身和里面的一切继续运行，与窗口关闭或连接断开时一样。关闭预览标签页则放开它的文件。

标签页里还有命令在运行时，Shellder 会先问：“关闭此标签？”，并说出是哪条命令。命令是否在运行由 Shell 集成报告；这个询问可以在控制台设置窗口里关掉（“关闭仍有命令运行的标签前先询问”，见[控制台设置](console-settings.md)）。

## 恢复关闭的标签页

`⌘⇧T` 或 `⌘Z` 把最近关闭的终端标签页开回来，并重新运行它的命令：shell 回到同一个目录，会话重新连接。它原来所在的分组还在时，回到那个分组；否则回到拥有键盘焦点的分组。再按一次，恢复的是更早关闭的那一个。预览标签页和一次性操作的标签页不能这样恢复。

## 已结束的标签页

命令正常结束（`exit`、分离）的终端标签页会自己关闭。以其他方式结束的，则留下来成为已结束的标签页：名称变成斜体，最后的输出留在屏幕上，并有一行说明它已关闭以及退出状态；在里面按回车重新连接。

## 标签标记、主机标注与标签进度条

**标签标记**是未显示的标签页上的一个圆点。它说明这段时间里那边发生了什么，选中这个标签页后就消失。

| 圆点 | 含义 |
|---|---|
| 橙色 | 那里的终端响铃响过，或就绪提醒响过。 |
| 绿色 | 那里有一条命令完成了。 |
| 红色 | 那里有一条命令失败了。 |
| 灰色 | 那里有新输出。 |

绿色和红色圆点需要 Shell 集成，由它报告命令何时结束、结果如何。终端响铃和就绪提醒见[终端内部](console-terminals.md)。

**主机标注**是标签页开头的主机名（本机显示为“本机”），出现在运行于别的主机、而不是窗口当前显示的主机的标签页上。用主机菜单或主机轮盘把窗口切换到另一台主机之后就会看到它：已经打开的标签页保持原样，各自留在自己运行的主机上（见[控制台](console.md)）。

**标签进度条**是标签页底部的一根细条，在里面的程序报告进度期间显示（见[终端内部](console-terminals.md)）。

## 标签页的右键菜单

| 菜单项 | 作用 |
|---|---|
| “向右分栏” | 在右边再开一个分组，显示这个标签页显示的内容。 |
| “向下分栏” | 在下面再开一个分组，显示这个标签页显示的内容。 |
| “保留此标签页” | 把临时标签页变成固定标签页。只在临时标签页上出现。 |
| “关闭” | 关闭这个标签页。 |
| “关闭本组中的其他标签页” | 关闭分组里其余的所有标签页。只在分组里不止一个标签页时出现。 |

## 分组

### 分栏

分栏是在一个分组的旁边或下面再放一个分组。有三种做法：

- 分栏按钮，也就是分组按钮里的最后一个：它的菜单提供“向右分栏”和“向下分栏”；
- 标签页右键菜单里的“向右分栏”和“向下分栏”；
- `⌘D`（向右）和 `⌘⇧D`（向下），作用于拥有键盘焦点的分组。

新分组显示原标签页显示的内容。终端的命令会再运行一次：同一个目录里的又一个 shell，或对同一个会话的第二次连接。预览的文件会再显示一次。一次性操作的标签页则换成一个普通的 shell。新分组一开始沿用原分组的背景选择。

### 拖动标签页

标签页可以拖到别的位置。拖动时，指针下的放置区会显示出来：

| 放置区 | 放下之后 |
|---|---|
| 标签栏 | 标签页移到那里，插在放下位置的两个标签页之间。在它自己的标签栏里，这就是调整标签页的顺序。 |
| 分组的边缘（左、右、上或下） | 分组在那一侧分栏，标签页进入新的分组。 |
| 分组的中间 | 标签页移进这个分组，排在最后。 |

最后一个标签页被拖走的分组会消失。

### 分隔线

两个分组之间的分隔线可以拖动。用键盘：`⌘⌃` 加方向键把拥有键盘焦点的分组的分隔线朝那个方向移动，每次十个像素；`⌘⌃=` 让每个分栏里的分组一样大。

### 移动键盘焦点

在分组里点一下，它就得到键盘焦点；新标签页开在拥有键盘焦点的分组里。

| 快捷键 | 把键盘焦点移到 |
|---|---|
| `⌘]` | 下一个分组（从左到右，从上到下）。 |
| `⌘[` | 上一个分组。 |
| `⌘⌥` 加方向键 | 那个方向上的分组。 |

在最左边的分组里按 `⌘⌥←`，键盘焦点会继续移进侧栏，见[控制台](console.md)。

### 单独显示

`⌘⇧↩` 让拥有键盘焦点的分组单独显示：只有它，占满整个标签区。下列情况下其他分组会回来：

- 再按一次 `⌘⇧↩`；
- 点击标签栏里取代了分栏按钮的那个按钮；
- 键盘焦点移到另一个分组；
- 布局发生任何变化。

### 关闭分组

最后一个标签页关闭后，分组随之消失，它的空间归相邻的分组。`⌘⌥W` 关闭拥有键盘焦点的分组，连同它的所有标签页；其中还有命令在运行的标签页会像单独关闭时那样先询问。

最后一个分组会留下，里面是空的：它会提示没有打开的标签页，按 + 可以开一个 shell。没有打开的标签页时，`⌘W` 关闭窗口。

## 分组按钮

标签栏右端的按钮，不管有多少标签页，它们都看得到：

| 按钮 | 作用 |
|---|---|
| 分组的就绪提醒（铃铛） | 为分组的所有标签页打开或关闭就绪提醒，新开的标签页也包括在内。见[终端内部](console-terminals.md)。 |
| 背景按钮（太阳或月亮） | 让分组的终端使用深色或浅色背景，不管系统外观是什么。当前显示的是预览标签页时，它对分组里各个预览显示的文件做同样的事，这是另一个独立的选择：深色的 shell 可以挨着浅色的文件。 |
| 分栏按钮 | 提供“向右分栏”和“向下分栏”。分组单独显示时，它的位置上是一个恢复其他分组的按钮。 |

背景选择随布局一起保存。具体的颜色是在[控制台设置](console-settings.md)里选的配色。

## 布局随窗口恢复

布局保存在本机，记在窗口显示的主机名下，每次变化都会保存。再次打开的控制台窗口会恢复成关闭时的样子：

- 各个分组、它们的分栏和分栏的大小；
- 每个分组的标签页、它当时显示的标签页，以及标签页是不是临时的；
- 每个分组的背景选择和就绪提醒；
- 当时拥有键盘焦点的分组。

终端标签页各自在自己的主机上重新连接，并运行各自的命令：在控制台里创建的会话会重新连接，已经不在了就重新创建。预览标签页显示各自的文件。

有两样东西不会恢复：

- **每个分组的普通 shell 只恢复一个**：当时显示的那一个（当时显示的不是 shell 时，是第一个），回到它的目录。各个分组按原样排布，每组一个 shell，而不是为每个屏幕内容反正已经丢失的 shell 都登录一次。
- **一次性操作的标签页**（例如交互式作业）不保留；只有这类标签页的分组也不会恢复。

切换到另一台主机的窗口保留它的标签页，此后它的布局记在那台主机名下。沉浸模式和快捷终端的标签页不保留，见[控制台的窗口功能](console-window.md)。
